# DeskIsle

Windows 11 x64 桌面文件夹卡片工具。当前源码为 **1.3.0 悬浮 Dock 版**，支持卡片内拖动排序、点击标题重命名、深色菜单、多卡片、导入到桌面和矢量图标；已生成 Windows x64 自包含包，Windows交互效果待用户验收。

## 运行

解压 `artifacts/DeskIsle-1.3.0-win-x64.zip`，双击目录中的 `DeskIsle.exe`。这是自包含目录版，请保留同目录全部文件；无需安装 SDK 或运行时。未经签名，首次运行可能出现 Windows 提示。

从微信、下载目录或其他位置拖入文件/文件夹时，先复制到Windows实际桌面，再加入当前卡片；原件保留。桌面根目录已有项目拖入空白区域只加入分组，不重复复制。卡片仅展示桌面直接子项，子目录内部项目不会单独展示；从桌面子目录拖到卡片空白处会实际移到桌面根目录并加入分组；移入文件夹后从所有卡片顶层消失，真实文件保留在目标文件夹。外部拖到卡片文件夹中央时复制进去；同一卡片内拖到文件夹中央直接真实移动，只有同名冲突时询问。左右插入线始终只排序。卡片内新建文件固定保存桌面根目录，无位置选择或任意目录浏览/定位入口。

同名文件用深色弹窗选择覆盖/跳过/取消，同名文件夹可合并，目标独有内容保留；内部同名文件另行询问。覆盖通过完整暂存后替换，旧文件保存在桌面隐藏`.DeskIsle-data`目录，配有原目标路径JSON，可从进度窗“恢复文件目录”打开。不要在需要恢复旧版本时清理该目录。文件与文件夹类型冲突不整项替换。批量取消保留已完成项，失败信息可在完成窗口查看。

升级后旧外部引用只在待迁移清单保留，不作为正常文件操作。首次提醒并在`%LOCALAPPDATA%\DeskIsle\cards.before-desktop-*.json`备份原配置；用户确认后复制导入，支持重试未完成项目。菜单可再次导入或只移除旧记录。配置升级为schema3，旧版本不可继续用它写入。

单击选中、双击系统打开；拖出上传提供桌面实际路径。右键“移出卡片”只解除分组，“删除”回收桌面真实文件。卡片标题、布局和背景设置沿用；默认过滤系统/隐藏项目，不支持经链接/目录联接或云占位路径操作，普通`.lnk`只作为快捷方式文件本身处理。详见 `docs/桌面文件模式交付.md`。

启动尝试桌面模式，失败明确降级；可手动切换浮动模式或重试桌面模式。桌面模式依赖未公开的 Explorer WorkerW 层级，不保证所有 Win11 版本行为相同。普通浮动模式不是桌面嵌入，Win+D 可能隐藏卡片。未通过用户实测前，不将桌面附着成功等同于兼容性通过。

## 开发与发布

- `src/DeskIsle.Core`：可跨平台的直接目录读取和排序。
- `src/DeskIsle`：WPF 窗口及隔离的 Windows 桌面宿主。
- `tests/DeskIsle.Core.Tests`：临时目录自动化测试。
- `scripts/publish.ps1`：Windows 自包含发布和 ZIP 打包。

锁定 SDK 10.0.403。下载官方 Windows x64 SDK ZIP，验证官方 SHA-512 后解压到 `.tools/dotnet-win`。SDK 下载地址及散列可在官方发布元数据查找：
https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json

在 Windows PowerShell 从仓库根目录运行：

```powershell
& ./.tools/dotnet-win/dotnet.exe test tests/DeskIsle.Core.Tests/DeskIsle.Core.Tests.csproj -c Release
./scripts/publish.ps1
```

WSL 可通过 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$(wslpath -w "$PWD/scripts/publish.ps1")"` 调用 Windows 发布脚本。不要同时运行发布和测试，二者共享核心库构建目录。

## 当前边界与后续

当前已支持引用及布局保存，配置位于 `%LOCALAPPDATA%\DeskIsle\cards.json`。首次启动从旧`card.json`迁移收藏，旧文件保留不改。程序启动后默认隐藏全部原生桌面图标（包括开机启动）；选择菜单“显示桌面图标”恢复，退出全部卡片时恢复，异常退出后重启尝试恢复。更多菜单提供恢复入口。每次启动均执行一次默认隐藏，手动恢复后本次运行不再自动隐藏。

0.4.2已完成构建和自包含发布，发布包放到Windows桌面供用户测试。以后每次功能或修复交付自动生成新包；自动测试和Windows交互验收另行记录，不把构建成功当作功能验收通过。

桌面嵌入仍存在兼容限制，窗口可降级为浮动模式；已提供文件事件监听与30秒兜底，托盘尚未完成。详细操作记录和待验收项目见 `docs/收藏卡片交付.md`。

移除程序前先通过菜单恢复桌面图标并正常退出，然后删除发布目录；删除 `%LOCALAPPDATA%\DeskIsle` 会清除收藏和恢复标记，请在确认图标已恢复后操作。程序不创建开机启动入口。

## 多卡片操作

- 点击卡片标题重命名：点击输入框外的卡片区域、Enter或失焦保存，Esc取消；只改变卡片标题。拖动标题旁空白区域移动卡片。
- 菜单“添加新卡片”创建独立空卡片；每张卡片的引用、标题、位置、大小和背景不透明度分别保存。
- 菜单“卡片外观”调节当前卡片背景；文件右键菜单和提示也统一为深色样式。
- 菜单“移除此卡片”只删除该卡片配置，不删除真实文件；移除最后一张后退出。“退出全部卡片”保留布局，下次启动恢复。Alt+F4只关闭窗口，不删除配置。
- 桌面图标开关对所有卡片共享，添加新卡片或关闭单个窗口不会意外恢复图标。
- 使用紧凑圆角重命名框，图标缩到40 DIP，移除常驻数量及模式说明；模式详情可从菜单查看。
- 本轮分步提交，全部完成后才把最终包放到桌面。构建及发布校验结果见 `docs/多卡片交付.md`；Windows交互效果待用户验收。


## 卡片内排序

按住图标并拖动，青绿色插入线提示放置位置，松手调整顺序。源图标变淡，鼠标旁显示悬浮预览；靠近上下边缘可滚动，Esc取消。桌面分组保存手动顺序；绿色排序线不改变文件路径，蓝色“移入”则会在确认后移动真实文件。

提供网格内插入排序，不支持任意像素位置摆放；跨卡片空白处拖入可加入分组。外部文件会先复制到桌面。交付和待验收项目见 `docs/拖动排序交付.md`。

0.4.2使网格左右留白对称，并将同一行相邻文件之间的插入线统一绘制在间隙中心；末行沿用完整列宽保持对齐。详见 `docs/网格间距与插入线修复.md`。
