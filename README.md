# DeskIsle

Windows 11 x64 桌面文件夹卡片工具。当前源码为 **0.5.1 文件删除与恢复修正版**，支持卡片内拖动排序、点击标题重命名、深色菜单、多卡片、直接拖入引用和矢量图标；已生成 Windows x64 自包含包，Windows交互效果待用户验收。

## 运行

解压 `artifacts/DeskIsle-0.5.1-win-x64.zip`，双击目录中的 `DeskIsle.exe`。这是自包含目录版，请保留同目录全部文件；无需安装 SDK 或运行时。未经签名，首次运行可能出现 Windows 提示。

默认直接将文件或文件夹拖入空卡片，原文件位置、内容和属性保持不变。也可点击标题右侧“•••→浏览目录”查看目录直接子项；“收藏卡片”返回已保存引用。单击选中且不自动滚动，双击调用系统默认程序打开，目录交给资源管理器。右键可打开、打开所在目录或刷新。标题栏拖动，边缘缩放；透明度、显示模式、刷新和退出都在“•••”菜单中。图标为按类型配色的矢量图形，不改变系统图标、不生成文件缩略图。右键可移出引用或重新定位。此原型不改动、移动或删除展示的文件；默认隐藏系统和隐藏项目。

启动尝试桌面模式，失败明确降级；可手动切换浮动模式或重试桌面模式。桌面模式依赖未公开的 Explorer WorkerW 层级，不保证所有 Win11 版本行为相同。普通浮动模式不是桌面嵌入，Win+D 可能隐藏卡片。未通过用户实测前，不将桌面附着成功等同于兼容性通过。

## 开发与发布

- `src/DeskIsle.Core`：可跨平台的直接目录读取和排序。
- `src/DeskIsle`：WPF 窗口及隔离的 Windows 桌面宿主。
- `tests/DeskIsle.Core.Tests`：临时目录自动化测试。
- `scripts/publish.ps1`：Windows 自包含发布和 ZIP 打包。

锁定 SDK 10.0.403。下载官方 Windows x64 SDK ZIP，验证官方 SHA-512 后解压到 `.tools/dotnet-win`。SDK 下载地址及散列可在官方发布元数据查找：
https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json

在 Windows PowerShell 从仓库根目录运行：

```powershell
& ./.tools/dotnet-win/dotnet.exe test tests/DeskIsle.Core.Tests/DeskIsle.Core.Tests.csproj -c Release
./scripts/publish.ps1
```

WSL 可通过 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$(wslpath -w "$PWD/scripts/publish.ps1")"` 调用 Windows 发布脚本。不要同时运行发布和测试，二者共享核心库构建目录。

## 当前边界与后续

当前已支持引用及布局保存，配置位于 `%LOCALAPPDATA%\DeskIsle\cards.json`。首次启动从旧`card.json`迁移收藏，旧文件保留不改。“更多→隐藏桌面图标”仅在主动点击后隐藏全部原生桌面图标；再次选择“显示桌面图标”恢复，退出全部卡片时恢复，异常退出后重启尝试恢复。更多菜单提供恢复入口。隐藏状态不作为偏好保存。

0.4.2已完成构建和自包含发布，发布包放到Windows桌面供用户测试。以后每次功能或修复交付自动生成新包；自动测试和Windows交互验收另行记录，不把构建成功当作功能验收通过。

桌面嵌入仍存在兼容限制，窗口可降级为浮动模式；托盘、持续文件监听等尚未完成。详细操作记录和待验收项目见 `docs/收藏卡片交付.md`。

移除程序前先通过菜单恢复桌面图标并正常退出，然后删除发布目录；删除 `%LOCALAPPDATA%\DeskIsle` 会清除收藏和恢复标记，请在确认图标已恢复后操作。程序不创建开机启动入口。

## 多卡片操作

- 点击卡片标题重命名：点击输入框外的卡片区域、Enter或失焦保存，Esc取消；只改变卡片标题。拖动标题旁空白区域移动卡片。
- 菜单“添加新卡片”创建独立空卡片；每张卡片的引用、标题、位置、大小和背景不透明度分别保存。
- 菜单“卡片外观”调节当前卡片背景；文件右键菜单和提示也统一为深色样式。
- 菜单“移除此卡片”只删除该卡片配置，不删除真实文件；移除最后一张后退出。“退出全部卡片”保留布局，下次启动恢复。Alt+F4只关闭窗口，不删除配置。
- 桌面图标开关对所有卡片共享，添加新卡片或关闭单个窗口不会意外恢复图标。
- 使用紧凑圆角重命名框，图标缩到40 DIP，移除常驻数量及模式说明；模式详情可从菜单查看。
- 本轮分步提交，全部完成后才把最终包放到桌面。构建及发布校验结果见 `docs/多卡片交付.md`；Windows交互效果待用户验收。


## 卡片内排序

按住图标并拖动，青绿色插入线提示放置位置，松手调整顺序。源图标变淡，鼠标旁显示悬浮预览；靠近上下边缘可滚动，Esc取消。收藏卡片和目录视图都会保存手动顺序，文件路径、内容和属性不变。

本次提供网格内插入排序，不支持任意像素位置摆放或跨卡片拖动转移。外部文件拖入仍只添加引用。交付和待验收项目见 `docs/拖动排序交付.md`。

0.4.2修复拖动跨越图标/文字时反复清除预览的问题，同次拖动复用预览，拖动期间目标高亮统一绘制。交互效果待Windows用户验收，详见 `docs/拖动闪烁修复.md`。

0.4.2使网格左右留白对称，并将同一行相邻文件之间的插入线统一绘制在间隙中心；末行沿用完整列宽保持对齐。详见 `docs/网格间距与插入线修复.md`。

0.4.3将拖动高亮与插入绿线分开：高亮跟随鼠标命中的文件，左右半区只改变前后插入线。详见 `docs/拖动悬停高亮修正.md`。

0.4.4增加返回桌面的事件恢复：全屏/最大化窗口退出后，在Explorer桌面获得前台时恢复卡片显示和重绘；普通应用在前台时不拉高卡片、不抢焦点，不设为置顶。3秒检查仅作状态异常兜底。实际全屏切换效果待Windows验收，详见 `docs/全屏退出恢复修复.md`。

0.4.5完成26项自动回归和11项WPF组件检查，修复空目录不响应预取消令牌的问题。系统级全屏/Win+D、多屏和真实鼠标拖放仍待独立验收，详见 `docs/集中测试记录.md`。组件检查命令：`./scripts/windows-component-checks.ps1`。

0.5.0：卡片空白处右键→新建文件夹、TXT或Markdown。收藏卡片默认创建到实际桌面，可更改并记住保存位置；目录视图创建到当前目录。名称和完整保存位置在创建前显示，取消不留文件，同名不覆盖。优化全屏退出后的恢复调度，实际显示延迟待Windows验收，详见 `docs/恢复优化与新建文件.md`。本版没有重新运行上述0.4.5测试。

0.5.1：文件/文件夹右键“删除…”操作真实项目，默认请求Windows回收站并显示确认；不可回收位置请在系统提示中取消。不想删除真实文件时使用“移出卡片”。删除取消或失败保留引用；成功移除当前卡片对应引用，其他卡片中的同路径引用可刷新或移出。同步修正0.5.0恢复调度潜在回退，实际显示延迟待用户验收。
