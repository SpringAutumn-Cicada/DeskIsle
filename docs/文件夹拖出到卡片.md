# 0.7.3 文件夹拖出到卡片

- 桌面子目录文件或文件夹拖到卡片空白区域，真实移动到 Windows 实际桌面根目录，并加入当前卡片；源目录保留，成功移出的项目不再留在源位置。
- 桌面根目录已有项目只加入分组；桌面以外的来源仍复制，原件保留。
- 拖到卡片中某文件夹中央仍沿用原有导入行为；卡片内排序和拖出上传不变。
- 真实移动复用同名覆盖/跳过/取消及文件夹合并；跳过项目保留原位置，取消后不启动剩余批次。部分成功的目标文件夹仍可展示。
- 卡片仍仅展示桌面直接子项，不恢复内部文件引用。没有增加卡片说明文字或新弹窗。

## 验证与验收

本轮不运行自动化测试及 Windows 交互验收。待用户检查：从桌面子目录移出单个文件、整个文件夹、多项混合拖入、同名跳过/覆盖/取消、重启后分组恢复。不要使用仍在编辑的重要文件作为验收材料。
