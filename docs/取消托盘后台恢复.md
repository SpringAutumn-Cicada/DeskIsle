# 1.11.8 取消托盘后台恢复

- 分支 test，基于 5487f31，开始时工作区干净。项目专用 Windows SDK 已安装。
- 按用户要求彻底移除隐藏栏操作功能：删除托管/原生托盘扫描、自动展开与点击、进程归属识别、后台恢复及会话关联、选择目标弹窗和恢复诊断代码，共五个专用源文件。
- 删除为托盘恢复临时显示任务栏的访问状态、控制器恢复锁和取消逻辑、隐藏窗口历史缓存、后台预览标记及“打开恢复诊断目录”菜单。
- Dock 使用当前正常窗口快照，最小化窗口仍保留图标、预览和点击恢复；预览刷新时过滤真正隐藏的 HWND。关闭到托盘的窗口不再由 Dock 恢复或预览。
- 固定图标无正常窗口时使用普通应用启动，与右键打开新窗口一致；不再进行后台进程/托盘恢复判断。原生任务栏手动切换按钮继续保留。
- 历史文档和旧版本包保留作为可恢复记录；本地旧诊断文件不主动删除，新版不再读取或写入。
- 开发验证：源码调用关系核对；仅执行已授权的最终发布与包完整性校验。未运行测试、lint、独立类型检查或 Windows 交互验收。
- 用户验收待进行：最小化后从图标/预览恢复、多窗口与分屏预览、普通应用启动、无隐藏栏弹出和恢复目标弹窗。
