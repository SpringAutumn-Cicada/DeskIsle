# 0.4.3 拖动悬停高亮修正

用户明确要求：拖动时鼠标在哪个文件上就高亮哪个文件，只有插入绿线按左/右半区改变位置。

此前统一槽位几何时同时把高亮目标绑定到槽位右侧文件，导致鼠标位于左侧文件右半区时高亮了右侧文件。本次将真实命中的文件矩形独立用于高亮，槽位矩形仅用于绿线。鼠标在同一文件左右半区移动时高亮不切换，只切换前后插入线；同一间隙仍保持居中。文件间隙没有直接命中文件时不高亮，由原有最近位置规则提供插入线。

变更：MainWindow.Reorder.cs及版本号。引用顺序、左右对称网格、预览复用和边缘滚动保持不变，不改真实文件。

未运行自动测试或Windows交互验收。仅执行交付所需构建发布、ZIP完整性和复制哈希校验，结果完成后追加。待用户验收：在同一文件左右半区拖动、高亮跟随跨文件切换、间隙绿线居中、松手排序和重启恢复；既有桌面嵌入兼容限制仍在。
