# 0.3.1 重命名与简洁布局

分支：test。用户反馈重命名时点击卡片内部空白不会结束编辑。

## 修复和变更

- 空白区域不获取键盘焦点，原来只依赖LostKeyboardFocus导致编辑状态不退出。改为窗口PreviewMouseDown显式判断是否点在输入框以外，先保存并退出编辑，再继续原点击动作；保留Enter保存、Esc取消和失焦保存，窗口失活同样结束编辑。
- 标题输入使用自定义圆角TextBox模板（保留PART_ContentHost），柔和底色、边框和选中颜色；宽度随内容变化，范围120～240 DIP，不铺满标题栏。
- 删除常驻引用/项目数量和双击提示，移除底部浮动/桌面模式文字及其布局行；模式详情仍可在菜单查看。保留空卡片、拖放过程和失败提示，正常有内容时不占状态行空间。
- 按用户追加要求：图标48→40 DIP，单元格94×108→80×94 DIP，列距100→86 DIP，并相应缩小图标行和文件名字号。

## 验证与待验收

仅进行交付所需Windows自包含构建发布、压缩包完整性及桌面复制哈希校验；不主动运行自动测试或Windows交互验收。结果发布后追加。

用户验收：点击标题，修改后点击卡片空白、文件、菜单均结束编辑并保留相应点击动作；点击输入框内部仍可编辑；Enter/Esc、空白标题、中文输入、外部点击和重启恢复；已有文件不显示计数或模式注释，菜单可看模式详情；小图标在不同缩放下清晰且网格不溢出。桌面嵌入的既有限制保持不变。
