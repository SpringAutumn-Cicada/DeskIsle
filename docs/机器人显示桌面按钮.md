# 1.11.9 机器人显示桌面按钮

- 分支 test，基于 08f0561；恢复中断时确认工作区干净，之前只有只读检查，未重复提交或打包。项目专用 Windows SDK 已安装。
- 原显示桌面的屏幕图标替换为原创矢量机器人：单根偏置触角、圆润面罩、双眼、两侧短耳及悬浮底线，使用原 Dock 浅蓝与青色配色；未使用 B 站标志素材或照描轮廓。
