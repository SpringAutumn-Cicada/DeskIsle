# 开始菜单与 Dock 间距

版本：1.3.1，分支：test。

通过 Dock 打开系统开始菜单后，识别 StartMenuExperienceHost 的可见顶层窗口，使其底边位于 Dock 上方 12 DIP；主屏空间不足时请求缩小菜单窗口高度。保留系统开始菜单、焦点、层级和内容，不注入 Explorer，不修改全局配置。

菜单打开期间保持 Dock 显示。定位尝试有次数上限，避免与 Shell 无限争抢位置；关闭菜单后停止观察，并恢复已隐藏窗口的原始边界。仅处理本次从 Dock 发起的菜单和主屏窗口，不处理其他进程窗口。

开发自验：完成代码审阅；按项目授权执行发布构建和包完整性、复制哈希校验，结果见下方发布记录。未执行自动化测试或 Windows 交互验收。

用户验收待执行：开始菜单与手机侧栏是否完整位于 Dock 上方；不同缩放和分辨率下的菜单内容滚动、关闭重开、连续点击、退出恢复。Windows Shell 对位置和高度调整的接受情况取决于系统版本，无法仅凭构建确认；如系统拒绝调整，有限尝试后停止，不持续争抢。
