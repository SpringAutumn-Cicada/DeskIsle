# 2.1.2 预览圆角修复

- 分支 test，基于 aba1fa5，初始工作区干净；已核对提交及 WindowPeek 历史、AGENTS，专用 SDK 与依赖存在。
- 原全尺寸预览层为不透明 WS_POPUP，没有继承源 HWND 的系统圆角轮廓，可能把角落填成直角，造成视觉外沿突变。
- 为画面层设置 DWMWA_WINDOW_CORNER_PREFERENCE，读取源窗口明确的圆角/小圆角/直角偏好；默认标准可调整大小标题窗口请求圆角，自定义无边框默认直角。最大化/IsWindowArranged 贴靠窗口优先直角。
- 同时缓存最小化前的轮廓偏好，避免最小化后丢失贴靠状态导致组合被强制圆角。源窗口不存在后清除缓存。
- 禁止画面层额外绘制系统边框，避免新增边线；只设置本地预览 HWND 的 DWM 属性，位置尺寸映射与真实窗口布局不变。DWM 圆角请求由系统决定，不保证所有自定义窗口轮廓完全复刻。
- 未运行测试、lint、独立类型检查、浏览器或 Windows 交互验收。用户待验收：普通终端圆角、最大化/贴靠直角、最小化组合、原始边界对齐及高DPI。

- 首次发布发现 CS1503：缓存轮廓调用误传 DockWindow 对象，已改传 Handle；失败构建未交付，修正后重新发布。
