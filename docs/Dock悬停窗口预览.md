# DeskIsle 1.1.0 悬停窗口预览

- 悬停运行应用图标250ms，在上方显示窗口预览，单窗口亦支持；各项有标题、预览区和关闭按钮。
- 鼠标从图标移向面板保持显示，离开两者300ms后关闭；面板开启时Dock不自动收起。拖动、右键菜单、切回原生任务栏、全屏和退出关闭预览。
- 点击预览恢复并激活对应窗口，关闭按钮请求关闭对应窗口，不强制结束进程；应用自己的保存提示保留。
- 直接点击图标不再弹窗口列表：前台组最小化当前窗口，否则激活最近使用窗口；尚无记录则选择可见非最小化窗口。
- 面板通过DWM缩略图显示画面，不截图、不注入来源进程。最小化窗口和DWM不可用时以图标、标题和切换按钮降级；不承诺受保护内容可预览。
- 预览按窗口而非Edge标签页。每页最多4个，按主屏工作区宽度收缩，更多窗口分页；关闭窗口后面板移除失效项。
- 保留1.0.4的图标提取显示、控件复用、排序、自动启动和空桌面常驻。

依据：[微软DWM缩略图文档](https://learn.microsoft.com/en-us/windows/win32/dwm/thumbnail-ovw)，关系注册后更新目标像素区域，关闭时注销。预览为本进程非分层顶级窗口，缩略图不覆盖标题/关闭按钮。

## 文件

新增 `Dock/WindowThumbnail.cs`（DWM资源）、`Dock/WindowPreview.cs`（面板与分页），修改 `DockWindow.xaml.cs` 悬停与点击、项目版本及README。未修改用户配置、真实文件、卡片文件操作及当前桌面状态。

## Windows 待验收

1. Edge两个独立窗口悬停即出现预览；鼠标跨间隙、停在面板不闪退，移开后关闭。
2. 点击各预览可分别激活，关闭其中一个窗口后其他窗口保留；多于4个窗口可翻页。
3. 单窗口、最小化、特殊/受保护应用的降级均可点击切换。
4. 原图标最小化、最近窗口激活、排序、右键、任务栏切换、全屏和退出无预览残留。
5. 不同缩放下位置/比例正确，不遮挡关闭按钮；多屏行为待实测。

本轮不运行自动化测试、lint、独立类型检查或Windows交互验收；只执行交付构建及包校验，结果完成后追加。
