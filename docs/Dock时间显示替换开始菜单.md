# Dock 时间显示替换开始菜单

版本 1.7.0；分支 test。

按用户要求删除 Dock 开始菜单功能：移除开始按钮、快捷键发送方法、StartMenuPlacement 及其进程扫描/边界修改/恢复逻辑，不再对系统开始菜单定位。Windows 自身开始菜单和键盘 Windows 键仍由系统负责。

原左侧区域替换为仅显示时间的固定宽度模块：24 小时制 HH:mm，等宽 Cascadia Mono/Consolas 字体，23 DIP 冷蓝白数字，底部窄渐变细线，不显示日期、秒或多余标签，不绑定点击动作。字体缺失时系统回退。时钟每秒读取当前本地时间，仅分钟文本变化时更新；Dock 隐藏时停止时钟计时，重新显示立即校准，关闭后停止计时。同步增加应用滚动区宽度预留，保留原有显隐动画。

开发自验：开始前工作区干净，检查 Git 近期提交及相关文件历史，项目专用 SDK 已安装，完成代码审阅。未运行测试、lint、独立类型检查或 Windows 交互验收。发布及包校验另记。

用户验收待执行：时间准确及分钟切换、隐藏后恢复/系统校时、字体和高 DPI 清晰度、Dock 居中和滚动布局、开始菜单不再被程序移动、显隐动画。外观和交互未经 Windows 验收。

续接核对：原实现提交 18a709e 已完成，工作区干净；旧发布会话与相关进程已结束，1.7.0 压缩包不存在，因此补做最终发布，未重复修改功能。
