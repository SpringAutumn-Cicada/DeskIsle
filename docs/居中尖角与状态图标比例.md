# 1.11.4 居中尖角与状态图标比例

分支 test，基于 f37bb5a；开始工作区干净，相关历史已核对，项目 SDK 已安装。

问题定位：原来弹窗为避免越过屏幕边界会横向移动，尖角则继续指向按钮，导致截图中尖角偏到右侧。按用户最新要求固定尖角在面板底边几何中心，删除锚点偏移逻辑。面板仍优先居中对准入口，靠近屏幕边缘时保证面板可见，尖角始终居中，不再追随按钮偏移；保留原间距。

Dock 状态图标改为相近槽位、统一间距，音量稍放大，电池实际绘制宽度从约 38 DIP 降至 28 DIP，外部占位从 48 降至 34 DIP。电池及端子使用实际曲线圆角，数字仍置于电池内部；有线网络和断网图标也使用圆角屏幕轮廓。保留充电/低电量/未知状态和四档音量功能，应用品牌图标不改。

实际开发验证仅人工源码审阅。未运行测试、lint、独立类型检查、浏览器或 Windows 交互验收。最终按用户持续授权自动打包复制桌面，完整性校验追加，不将构建成功记作视觉验收通过。
