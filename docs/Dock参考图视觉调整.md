# DeskIsle 1.2.5 参考图视觉调整

按用户参考图调整纯内容预览，不新增说明文字。

- 单窗以160 DIP内容高度为基准，最大宽320 DIP，过宽时按比例降低高度，不裁剪画面。
- 组合以300 DIP总宽为基准，左右按原布局宽度比例分配，不再强制等宽。
- 全行按屏幕宽度和工作区高度35%上限统一缩小，避免组合与单窗大小失衡或超出屏幕。
- 内容周围使用4 DIP蓝灰边框，按DPI换算；默认深灰蓝，悬停柔和亮灰蓝，保持按下反馈。卡片间距统一，内容垂直居中。
- 外框圆角收至10 DIP，保持紧凑、不加标题与注释。来源画面自带空白不裁切。

修改WindowPreview.cs、WindowThumbnail.cs、版本及README，未修改预览激活/停留、分屏恢复、图标或文件操作逻辑，用户配置与文件未改。

未运行自动化测试、lint、独立类型检查或Windows视觉/交互验收。需用户按参考图检查单窗、组合、窄长窗口、小屏和不同DPI的均衡效果；交付构建与包校验不替代视觉验收。
