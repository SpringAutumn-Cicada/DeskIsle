# DeskIsle 1.1.1 预览、底边与开始菜单

## 中断核对

开始时工作区干净，最新0e35de7，未发现中断遗留修改。SDK已安装，未运行旧程序或重复复制旧包。

## 实现

- 取消最小化窗口的缩略图排除条件：对所有有效窗口尝试DWM画面，最小化时优先利用系统保留的帧。独立原生非激活、禁用输入画面层避免WPF内容覆盖DWM图像；点击由下面的预览卡片接收。
- 缩略图在有效布局后注册，失败后可重试，关闭/翻页注销并释放原生窗口。系统不提供画面时显示明确提示，不强行恢复来源窗口、不截图保存内容、不声称能预览受保护画面。
- 面板增加圆角、顶部窗口数量、较大248×148 DIP预览和更清晰标题，超过工作区宽度时分页。
- 唤出区域改为主屏全宽底部6 DIP；到边停留后每次主动恢复Z序，不再只检查WPF是否可见。普通最大化不再当作全屏，带标题栏普通最大化排除全屏判断，无边框全屏继续按尺寸避让。仍仅主屏启用Dock。
- Dock左侧新增系统开始菜单按钮，发送完整Windows键按下/释放。保留系统菜单及搜索，不自建应用清单，不修改任务栏自动隐藏设置。系统拒绝输入时提示使用Windows键。

## 文件范围

`WindowPreview.cs`、`WindowThumbnail.cs`：预览；`DockController.cs`、`DockNative.cs`：唤出与系统入口；`DockWindow.xaml`/`.xaml.cs`：开始按钮；项目版本、README和本记录。

用户文件、配置及原卡片操作未修改。图标仍保持1.0.4已恢复方式。

1. Edge普通窗口和最小化窗口悬停时均尝试显示网页内容，禁止为预览擅自恢复窗口；特殊/受保护内容允许提示降级。
2. 鼠标移到面板、关闭窗口、切换、翻页、离开后收起，画面层无残留且不阻挡点击。
3. 主屏底部左/中/右都可唤出，普通最大化应用下可用，真正全屏仍避让；不同缩放及显示器位置分别确认。
4. 开始按钮能打开系统开始菜单、键盘搜索及关闭菜单正常，原生任务栏切换入口保留。

开发未执行自动化测试、lint、独立类型检查或Windows交互验收；仅执行交付构建及包校验，实际结果随后追加。
