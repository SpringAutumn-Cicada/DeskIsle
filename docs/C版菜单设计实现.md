# 2.2.2 C版菜单设计实现

- test基于09ce60e，工作区干净；已核对菜单历史、AGENTS、SDK及依赖。
- 按用户选定C稿重绘矢量：叠层添加卡片、双层铅笔/文件夹、双色刷新、薄荷星标和斜图钉、分层显示器、带孔调色盘、浅盖深桶、横向双滑杆、电源。
- 使用固定24单位透明画布，19DIP实际图标，避免各几何外框不同造成尺寸漂移；浅青#A3D7C9、深青#44847B、薄荷#72DEC2和灰白层次，悬停透明度提亮，状态关闭降低透明度。
- 卡片菜单局部改为C稿深色渐变，不影响其他窗口全局主题；保留菜单尺寸/功能、唯一default和固定状态即时更新逻辑。
- 设计图是栅格视觉参考，以矢量重建轮廓和层次；未做Windows截图逐像素比对，不能声称已验证一模一样。系统字体/DPI可能导致差异，待用户视觉验收。
- 未运行测试、lint、独立类型检查或Windows交互验收；按项目授权最终发布D:\Mine，保留旧包。
