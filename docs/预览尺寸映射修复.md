# 2.1.0 预览尺寸映射修复

- 基于 5306080，分支 test，开始时工作区干净；已核对近期提交、文件历史、AGENTS，项目专用 SDK/恢复依赖存在。
- 全尺寸 DWM 预览此前直接铺满 GetWindowRect 外框，没有核对源图尺寸与可见边框差异。
- 增加可见边界 DWMWA_EXTENDED_FRAME_BOUNDS 读取；分屏缓存同时保存外框与可见边界，供最小化预览使用。非法或超出外框的可见边界回退外框。
- 注册 DWM 后查询真实源尺寸：与外框一致时裁剪不可见边框；与可见尺寸一致时一对一显示；其他缓存尺寸按比例缩小居中，禁止放大。不使用固定像素边框或固定缩小百分比。
- 保留仅创建本地画面层的方案，不移动/展开/最小化源应用。源缓存尺寸不同可能出现留白；最小化后仍可能为缓存帧。首次已最小化且无记录的窗口不能保证重建准确可见边界。
- 用户指定版本 2.1.0，后续包目录改为 D:\Mine；同步项目 AGENTS 交付约定，保留旧包，不修改全局配置。
- 未运行测试、lint、独立类型检查、浏览器或 Windows 交互验收。用户待验收：普通/最大化/组合预览与真实窗口大小对齐、高DPI多屏、最小化画面、移开关闭及点击打开。
