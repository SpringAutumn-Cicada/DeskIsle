# 2.1.1 预览偏移修复

- 分支 test，基于 387ac23，工作区原本干净；已核对近期提交、相关文件历史、AGENTS，项目 SDK 与依赖存在。
- 画面层已位于可见边框左上角，旧逻辑在源画面尺寸略小或按比例缩小时又添加 (目标尺寸-绘制尺寸)/2，使画面出现额外右移/下移。
- 目标绘制矩形固定从画面层 (0,0) 开始，尺寸不匹配的剩余区域留在右侧/底部；保留真实源尺寸查询、可见边框裁剪、等比缩小和禁止放大。不移动真实应用窗口，不改写分屏矩形。
- 未运行测试、lint、独立类型检查、浏览器或 Windows 交互验收。开发侧仅代码审阅及授权发布校验；用户待验收：普通/组合窗口左上边界对齐、最小化缓存尺寸差异、高DPI多屏。
- 限制：该修复消除代码中的额外居中偏移，尚未以 Windows 运行数据确认用户所见偏移是否还含其他来源；缓存画面仍可能留白。
