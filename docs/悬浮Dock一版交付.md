# DeskIsle 1.0.0 悬浮 Dock

## 启用与使用

退出旧版后解压新包，双击 DeskIsle.exe。卡片菜单 →「悬浮 Dock 设置…」→ 勾选启用并保存。首次安装默认不接管任务栏，原有卡片和分组沿用。

- 底边中央 70% 区域停留后唤出主屏 Dock，移开后收起。默认等待 120ms / 收起 650ms，可在设置调整。
- 拖入 `.lnk`、`.exe` 或 `.appref-ms` 固定应用；拖到另一个固定图标前调整顺序，青色线标出插入位置。
- 图标右键：打开、取消固定、重新定位、打开所在位置；运行应用可固定。路径失效时图标变淡。
- 点击固定应用启动；已有一个窗口时激活，多窗口时弹出标题列表。右键窗口子菜单可切换或请求关闭窗口。
- 右侧「▤」显示原生任务栏，Dock 收起；点击独立「返回 Dock」按钮恢复 Dock。返回按钮可拖动，右键可关闭接管。
- 默认 Ctrl+Alt+D 切换原生任务栏 / Dock。字母可修改，占用时会提示；按钮仍可使用。
- 全屏占据主屏时收起 Dock 和返回按钮，退出全屏后可重新到底边唤出；不接管副屏任务栏。
- Dock 设置可调整透明度；取消启用后恢复原生任务栏，卡片继续工作。

## 系统边界与恢复

仅控制主屏原生任务栏窗口显隐，不修改自动隐藏设置、工作区保留区域、系统文件或 Explorer 进程。原生托盘、输入法、音量、网络、日历等通过切换回原生任务栏使用。

正常退出恢复接管前可见状态。独立 DeskIsle.exe --taskbar-watch 守护进程等待主程序结束，尝试恢复任务栏；Explorer 暂不可用时最多重试 30 秒，下次正常启动也会检查恢复记录。

恢复记录位于 `%LOCALAPPDATA%\DeskIsle\taskbar-recovery.json`。主程序退出后，若任务栏仍未恢复，可双击发布目录 `Restore-Taskbar.cmd`。手动恢复拒绝接管仍在运行的实例，避免两个程序争抢状态。恢复记录在任务栏尚不可用时保留；不要手动删除唯一恢复材料。

配置 `%LOCALAPPDATA%\DeskIsle\dock.json` 独立于卡片配置，原子保存并保留 `.bak`。损坏或未知版本配置禁止接管并保留原文件。

## 实现与限制

- Dock 为独立 WPF 窗口，使用深色圆角、轻阴影、图标悬停缩放和运行指示；不持续模糊。
- 固定应用按快捷方式目标 EXE 归组，Shell 启动保留原快捷方式参数。无法读取进程信息的窗口独立显示，商店应用可能归组不完整；不提供任务栏跳转列表或实时缩略图。
- 图标取自系统 Shell，最多两个并行加载、256 项内存缓存。部分应用仅提供低分辨率图标，清晰度受原图限制。
- 窗口变化事件合并 180ms，3 秒兜底扫描；80ms 指针检测仅在启用时运行。无高频任务栏隐藏循环。
- 标准主屏工作区用于返回按钮定位，Dock 基于主屏原生像素边界转换 WPF 坐标。不同 DPI、多屏切换、休眠/锁屏、独占全屏需要用户实测。
- 任务栏 SHOW 事件触发隐藏，Explorer 重启后重新发现窗口；该方式依赖 Explorer 兼容性，不保证所有系统版本无闪现，不承诺全屏恢复零延迟。
- 首版不重做系统托盘、输入法、通知，不改变开机启动配置；现有开机启动指向新目录后才使用新版本。

## Windows 验收待执行

1. 首次不接管，启用后底边只唤出 Dock；原生任务栏按钮、返回按钮和快捷键反复切换。
2. 固定、排序、重启恢复，快捷方式参数正确；无效路径可重新定位。
3. 多窗口切换、最小化后激活、关闭窗口、管理员应用和商店应用分别检查。
4. Win+D、Alt+Tab、开始菜单、托盘弹层、最大化与全屏、Explorer 重启。
5. 异常结束主实例后守护恢复；正常退出恢复；不同缩放、多屏断开、锁屏解锁和休眠恢复。
6. 记录机器配置、空闲 CPU/私有内存、启动与底边唤出表现。不要将构建成功当成功能验收通过。
