# 0.5.0 恢复调度优化与右键新建

## 第一步：恢复调度

将恢复工作从Background队列改为Render优先级，保留事件合并。固定350ms补偿改为仅在切换期间启动的16ms有限重试：观察到WPF渲染事件且至少重试一次后停止，最多8次计时回调，非实时调度、不保证128ms内一定执行完。帧监听仅在过渡期间订阅并释放，不常驻逐帧刷新。既有不抢焦点、不置顶、空闲兜底不重绘规则保留。

增加可选时序采样：启动前在该进程设置 `DESKISLE_RECOVERY_TRACE=1`，记录事件、Dispatcher执行、恢复调用及WPF帧时刻，最多256条，空闲异步写入 `%LOCALAPPDATA%\DeskIsle\recovery-timing.csv`，默认关闭。不记录文件路径、文件内容或其他应用标题。WPF Rendering事件不等于实际显示器呈现，不能据此宣称零延迟。

本轮未执行交互测试或性能对照测量，不能承诺“无任何卡顿”。透明窗口/原生合成方案没有实测依据，暂不改动现有视觉与渲染技术栈；需要在实际全屏程序上用时序采样配合录屏对照后再决定。
