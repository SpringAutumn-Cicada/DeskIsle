# 0.5.0 恢复调度优化与右键新建

## 第一步：恢复调度

将恢复工作从Background队列改为Render优先级，保留事件合并。固定350ms补偿改为仅在切换期间启动的16ms有限重试：观察到WPF渲染事件且至少重试一次后停止，最多8次计时回调，非实时调度、不保证128ms内一定执行完。帧监听仅在过渡期间订阅并释放，不常驻逐帧刷新。既有不抢焦点、不置顶、空闲兜底不重绘规则保留。

增加可选时序采样：启动前在该进程设置 `DESKISLE_RECOVERY_TRACE=1`，记录事件、Dispatcher执行、恢复调用及WPF帧时刻，最多256条，空闲异步写入 `%LOCALAPPDATA%\DeskIsle\recovery-timing.csv`，默认关闭。不记录文件路径、文件内容或其他应用标题。WPF Rendering事件不等于实际显示器呈现，不能据此宣称零延迟。

本轮未执行交互测试或性能对照测量，不能承诺“无任何卡顿”。透明窗口/原生合成方案没有实测依据，暂不改动现有视觉与渲染技术栈；需要在实际全屏程序上用时序采样配合录屏对照后再决定。

## 第二步：右键新建

卡片空白处右键→新建，支持文件夹、TXT、Markdown。面板显示完整保存位置、名称、取消与创建按钮，Enter创建、Esc取消。收藏卡片默认保存到Windows实际桌面，可以更改位置，创建成功后按卡片记忆；浏览目录时保存到当前目录。文件创建后自动加入收藏或刷新目录并选中。

默认名称跳过已有项目，选中主体并保留扩展名；检查Windows非法字符、保留名称、尾部空格和句点。使用原子CreateNew/原生CreateDirectory拒绝覆盖，不预先创建占位文件；取消不留文件。同名冲突、目录失效和权限不足显示错误。创建期间禁止退出、移除当前卡片和切换其模式，避免保存前关闭。原有引用文件不移动、不改写。只创建空白文档，不依赖Office，不加载第三方Shell新建扩展。

本轮未执行自动化或Windows交互测试；交付构建及压缩包检查结果另行记录，用户需验收全屏恢复、空白右键新建、取消、同名冲突、不同目录与多卡片。

## 0.5.1 恢复回退修正

用户反馈0.5.0偶发延迟更高。代码检查发现Render优先级重试与绘制竞争、WPF Rendering事件过早终止重试，以及Explorer层级修复触发的新事件可能不断重启重试窗口。上述是代码风险，尚无实测时序证明其占比。

撤销16ms渲染优先级循环和帧完成判据：使用低于渲染的Background调度，首次收到事件即排队恢复，额外在约100ms和350ms各补偿一次；不因事件风暴重启补偿窗口，补偿期间合并桌面层级变化事件。时间为非实时调度目标，不承诺实际显示时延。未改变透明窗口技术栈；全屏返回效果仍需用户实测。
