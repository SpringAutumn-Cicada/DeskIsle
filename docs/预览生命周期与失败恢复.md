# 预览生命周期与失败恢复

版本：1.3.3；分支：test。

## 修改范围

- 删除 Dock 图标侧第二套收起计时器，由预览自身统一判断鼠标位置。判定覆盖原生预览、关闭按钮所在区域、锚定图标以及图标到预览之间的间隙；离开上述区域连续 350 毫秒后收起。
- 窗口列表变化时，按 HWND 与单窗/组合身份复用原生缩略图及关闭按钮。仅释放消失或翻页后不再展示的缩略图；复用画面的点击回调指向最新动作，避免组合变化后仍执行旧动作。
- 不再因单次源窗口不可见立即删除预览；检查窗口句柄是否存活，列表仍由现有应用枚举同步。
- 关闭按钮仅在实际矩形变化时调用 SetWindowPos；定位失败不记录成功缓存，以便后续重试。
- 缩略图创建间隔至少 500 毫秒，同一展示项最多尝试三次；更新连续失败三次后释放失效关系，再按限额重建。成功更新会清除连续失败计数。达到上限后保留现有图标占位，重新打开预览会开始新的尝试。
- 组合识别比较当前实际展示的组合，避免以同一份更新后的几何缓存同时计算前后状态而漏掉组合变化。翻到非首页时不错误重复重建组合。

## 验证与限制

开发自验：仅代码审阅，未执行测试、lint、独立类型检查或 Windows 交互验证。按项目交付约定执行发布构建及 ZIP/复制校验，结果见发布记录。

用户验收待执行：图标到预览反复移动、关闭按钮悬停、Edge 单窗/双窗组合、分页及关闭一个窗口后的其余预览保持、Win+D 后恢复和不同缩放。

此次修改针对已确认的生命周期和重复定位问题；尚无 Windows 运行复现证据能证明涵盖所有不稳定来源。最小化窗口能否提供实时画面仍取决于 Windows DWM 和源应用；受保护内容等无法保证得到画面。
