# 代码发现

上版仍在 Button.Click（鼠标释放）时查询前台句柄，WPF 焦点/激活可能已经改变；WM_MOUSEACTIVATE 单独不足以覆盖焦点转移，缺少按下快照和窗口归属判断。此为代码推断，尚无本机交互复现。

图标仍有1.12倍 RenderTransform动画、父Border DropShadowEffect（子树离屏渲染）和HBITMAP转换路径。优先请求256像素原图，不用放大动画，阴影从内容父层拆出；用32位像素保留Alpha，避免有损重复缩放。源应用不提供高清素材时不能凭空恢复细节。

最终检视：独立阴影层改为透明描边，避免实色底层遮住背景不透明度设置。修改后重新生成最终包，未复制中间包。
