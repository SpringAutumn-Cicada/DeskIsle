# 发现

IsCardPath 当前允许整个桌面目录树；RecordTransfer 会在其他卡片保留移入文件夹后的路径，ImportDesktopFiles 也会添加显式文件夹目标里的文件，导致卡片重复展示内部文件。

方案：新增仅允许桌面直接子项的纯路径判断，独立于文件操作及文件夹浏览权限；顶层加载过滤隐藏/系统项。保存时仅移除桌面内部非直接子项引用，保留外部待迁移和暂不可用的顶层记录。导入空白处的桌面内部文件跳过，不复制到根目录。

发布校验遇到 ZIP 路径分隔符差异：PowerShell Compress-Archive 使用反斜杠；检查器归一化后确认 EXE 存在，CRC 正常。没有改动压缩包内容。
