# 现状依据

起点test/862b3a8且工作区干净。MainWindow.FileDrop仅将拖入的绝对路径加入References，因此微信来源继续指向微信目录。NewItem允许CreationDirectory和目录浏览决定位置，且有更改位置入口。菜单还提供浏览任意目录和重新定位引用。FileMoveService当前遇同名报错，不提供覆盖/跳过分支。

推荐统一物理存储与卡片分组：实际桌面根目录及其普通子目录为唯一业务文件范围；卡片是分组，不按标题另建目录，不改动同盘其他路径。入口统一检查规范路径和链接祖先，不凭字符串前缀判断。旧配置需备份并显式迁移，不能直接重写路径假装文件已导入。
