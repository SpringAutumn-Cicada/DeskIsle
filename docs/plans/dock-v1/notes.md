# 设计边界

原生任务栏通过窗口显隐控制，不注入 Explorer，不改变自动隐藏设置或系统文件。每次接管保存原状态，退出和独立进程恢复；窗口重建时重新发现。仅控制主屏任务栏。Dock 使用独立窗口，不依附桌面卡片宿主。

固定应用保存原始快捷方式路径，Shell 启动保留快捷方式参数；归组使用解析快捷方式的目标 EXE 路径，无法归组的窗口独立列出。窗口枚举后台进行，图标异步缓存；底边检测只读取鼠标和前台窗口几何信息。

发布构建首次发现 WPF Thickness 不支持两个参数；已改为左右上下四参数，属于编译修复，不涉及用户数据。

最终检视补充：底边唤出同时检查原生窗口可见性与最小化状态，防止 Win+D 后 WPF IsVisible 仍为 true；关闭接管时 Explorer 暂不可用则释放恢复记录的进程归属，守护进程继续重试而不等到整个应用退出。
