# 重命名、视觉及多卡片分步交付

分支：test。遵循每个完整步骤提交并生成自包含包的约定；仅执行交付所需构建及包校验，不主动运行自动测试或Windows交互验证。

## 第一步 0.2.1：点击标题重命名

点击标题进入编辑，Enter或失焦保存，Esc取消，空白标题保留原值，最多40字符；修改只影响卡片名称，不修改目录或文件名。拖动标题旁空白区域移动窗口。旧配置没有Title时默认“我的卡片”。标题写入原配置，恢复已有引用。

运行效果、输入法和重启恢复均待Windows用户验收。

## 第二步 0.2.2：统一深色菜单和卡片样式

隐藏/显示桌面图标改为“更多”菜单项，打开菜单前同步真实状态，不再占用卡片底部。新增全局深色ContextMenu、MenuItem（含子菜单）、按钮和ToolTip模板，使用圆角、细边框、统一间距和柔和高亮，去除系统菜单左侧灰色留白。透明度收进“卡片外观”子菜单。桌面图标依然只在用户主动操作后隐藏。

用户要求改为全部完成后才把最终发布包复制到桌面，因此中间版本不再单独交付。视觉和菜单交互待Windows用户验收。
