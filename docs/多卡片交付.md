# 重命名、视觉及多卡片分步交付

分支：test。遵循每个完整步骤提交并生成自包含包的约定；仅执行交付所需构建及包校验，不主动运行自动测试或Windows交互验证。

## 第一步 0.2.1：点击标题重命名

点击标题进入编辑，Enter或失焦保存，Esc取消，空白标题保留原值，最多40字符；修改只影响卡片名称，不修改目录或文件名。拖动标题旁空白区域移动窗口。旧配置没有Title时默认“我的卡片”。标题写入原配置，恢复已有引用。

运行效果、输入法和重启恢复均待Windows用户验收。

## 第二步 0.2.2：统一深色菜单和卡片样式

隐藏/显示桌面图标改为“更多”菜单项，打开菜单前同步真实状态，不再占用卡片底部。新增全局深色ContextMenu、MenuItem（含子菜单）、按钮和ToolTip模板，使用圆角、细边框、统一间距和柔和高亮，去除系统菜单左侧灰色留白。透明度收进“卡片外观”子菜单。桌面图标依然只在用户主动操作后隐藏。

用户要求改为全部完成后才把最终发布包复制到桌面，因此中间版本不再单独交付。视觉和菜单交互待Windows用户验收。

## 第三步 0.3.0：多卡片与共享生命周期

- 任意卡片菜单“添加新卡片”创建独立空卡片，各自重命名、拖入引用、调整位置尺寸和背景透明度。重复引用只在同一卡片内去重，不同卡片可收藏相同文件。
- 新配置保存到 `%LOCALAPPDATA%\DeskIsle\cards.json`，schemaVersion为2，包含卡片ID、标题、引用、位置尺寸及背景不透明度。原`card.json`及其备份保留不改，首次无多卡片配置时读取旧收藏作为第一张卡片。
- 全部卡片由应用统一持有，每次保存整份配置，避免不同窗口相互覆盖。500ms防抖保存布局，退出保存；有效备份、损坏恢复、未知版本只读保护保留。
- 桌面图标控制在应用级共享，新增或关闭单张卡片不恢复图标；所有卡片退出时统一恢复。各菜单显示同一真实状态，新增卡片不会自动重新隐藏图标。
- “移除此卡片”确认后仅删除该卡片配置，移除最后一张后退出，下次启动创建空卡片；“退出全部卡片”保留全部配置。Alt+F4关闭窗口不删除配置，重启恢复。
