# 2.0.1 启动与窗口恢复

- test 分支，基于 3e02dff；开始时工作区干净，项目专用 SDK 与依赖已安装。未修改全局配置。
- 原因：自启进程晚于系统启动约 33 秒，不能归因于代码量；Dock 原先只接管一次，没有等待 Explorer；最小化恢复为同步请求且不核对结果。
- 启动阶段诊断写入用户本地 DeskIsle/startup-diagnostics.log，后台串行写入，单文件约 256KB 轮换；记录时间、阶段、窗口句柄和提权状态，不记录标题、文件内容。进程入口时间不包含操作系统调度之前的等待。
- 每秒检查 Explorer 和旧任务栏恢复，最多 60 次；超时保留原生任务栏，可从卡片菜单打开 Dock 设置重新启用。退出或手动应用设置取消等待。
- Dock 准备好显现帧后才开始隐藏原生任务栏，避免先隐藏再创建失败。
- 单窗口恢复改为异步请求和有界状态核对，补发一次系统恢复消息，识别最后活动对话框；失败提示原生任务栏恢复，并记录目标与本程序提权状态。
- 权限限制仍可能导致管理员窗口无法恢复；本版没有提权辅助进程，也不将整个 DeskIsle 改为管理员。需要用户现场复现后从诊断记录确定是否需要辅助进程。双窗口分屏恢复保留原流程。
- Dock 设置增加“登录后立即启动”：当前用户交互式登录触发，无延迟、不保存密码、普通权限。任务使用当前 exe 路径，更新移动程序后需关闭再开启此选项以更新路径。
- 注册成功后迁移启动目录中指向 DeskIsle.exe 的旧快捷方式，保存在用户数据 startup-backup/links；更新前保存旧任务 XML，迁移失败回滚任务并恢复快捷方式，不覆盖同名文件。
- 关闭此选项会删除专属任务并恢复原快捷方式，因此有旧快捷方式的用户仍会按原方式自启。当前 Windows 自启配置尚未改变：用户需运行新版本，在固定位置打开设置启用此项。
- 未运行测试、lint、独立类型检查或 Windows 交互验收。发布和包完整性校验单独记录；开机速度、Dock、任务管理器/磁盘管理器恢复和任务注册待用户验收。
