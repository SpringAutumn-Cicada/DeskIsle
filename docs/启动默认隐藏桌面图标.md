# 0.5.7 启动默认隐藏桌面图标

按用户新要求覆盖此前“仅手动隐藏”的规则：程序启动后默认隐藏Explorer桌面图标视图，开机启动和双击启动行为一致。恢复上次异常退出标记后执行本次隐藏；隐藏前仍先保存恢复标记，失败不隐藏。开机时Explorer可能尚未就绪，每秒重试、最多30次后停止并提示，不持续轮询、不重新隐藏已由用户手动恢复的图标。手动显示/隐藏及恢复入口会取消启动重试。只在应用级启动执行一次，多卡片添加不重新隐藏。

退出仍恢复由本程序隐藏的图标，保留异常退出恢复机制；不修改文件属性、注册表或启动快捷方式。隔离组件模式DesktopIntegration=false不操作桌面。改动为WorkspaceManager、MainWindow、版本及说明。未执行测试或Windows交互验收，待用户确认双击启动、开机启动、菜单恢复、多卡片和退出。
