# 2.0.12 预览悬停临时查看

- 分支 test，基于 a1ac698；开始前工作区干净，核对近期提交、预览及原生窗口历史，项目专用 SDK 与依赖已安装。
- 按已确认方案实施，非完整 Aero Peek：不包含其他窗口透明淡出，不使用未公开 DWM 接口。
- 复用预览50ms鼠标位置检测（支持独立原生缩略图表面），悬停预览卡约300ms后临时展示，移动到其他预览或空白立即还原，原预览350ms移出关闭规则保留。
- 新增 WindowPeek 会话，记录窗口身份、placement、原最小化/最大化信息、层级前驱与置顶属性；异步无激活展示，普通窗口不变成置顶。原最小化窗口离开后无激活最小化，原已打开窗口仅还原层级；未改变无关窗口、未主动切换前台。
- 最大化后最小化的窗口补存窗口样式中的最大化状态，临时按工作区展示，正式点击恢复最大化信息。原生异步还原和最大化/分屏状态需要 Windows 验收，不能仅凭构建认定完全一致。
- 点击预览先提交对应单窗或组合会话，再执行既有激活/分屏恢复；关闭按钮先取消临时状态再发关闭，翻页、预览关闭、窗口列表变化重排统一清理。用户直接切换到真实窗口时不再将已选窗口最小化。
- 分屏观察跳过临时窗口，防止把预览中的布局当成用户新布局。窗口身份按句柄+进程+线程校验，窗口已销毁不再恢复；遮蔽、禁用窗口或请求失败时保留普通缩略图体验。
- 悬停不调用现有 Activate/SetForegroundWindow/SplitGroups.Restore，避免直接清除消息提醒；应用自身忽略无激活请求、权限限制、独占全屏、异步恢复和跨屏缩放仍可能影响效果。
- 版本 2.0.12，功能提交 ed5926e、3c29543、后续最大化修正。未运行测试、lint、独立类型检查、浏览器或 Windows 交互验收。
- 用户验收待进行：普通/最小化/最大化窗口、分屏组合与单窗交叉悬停、原生缩略图点击、关闭按钮、翻页、移出、应用退出、切换前台、消息提醒不被悬停清除、管理员窗口和高DPI。
