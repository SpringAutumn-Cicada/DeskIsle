# Dock 轻薄终端与直接后台图标

分支 test，基于 4141e18；本轮开始工作区干净，项目专用 SDK 已安装。

## 第一步：轻薄终端与系统状态一体化

二级面板由 66 DIP 收窄至 48 DIP，工具图标缩到 20 DIP，支架降至 8 DIP。左右各保留 128 DIP，中央后台区两侧使用等高分隔竖线。减弱光带与阴影，主 Dock 保留现状。

网络、声音、电量合并为同一悬浮/点击区域，点击通过 Win+A 请求 Windows 原生快捷设置；原来的分别跳转和自制音量弹窗移除。电量数字置于电池内部，充电标记独立显示，电池不存在时收起；读取失败显示横线。

参考：[微软 Windows 快捷键说明](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows)。SendInput 接受输入并不等于确认系统弹窗已显示；Windows 交互待验收。

## 第二步：后台应用直接显示

版本 1.9.1。中央固定容纳 4 个 22 DIP 应用图标，左右等宽，不因后台数量变化跳动；右侧省略号展开溢出的图标与完整原生托盘入口。保留现有图标控件和排序，异步读取图标，失败先保留名称首字并重试。窄屏二级终端整体等比缩小，主栏滚动区留足固定控件空间。

每两秒在后台线程读取一次进程快照，已知应用之外额外发现微信、QQ、TIM、企业微信、钉钉、Telegram、OneDrive。常见托盘客户端运行时保留入口，不因主窗口打开而消失；其他已知应用仅在当前窗口快照无可见主窗口时显示；过滤 Windows 目录中的系统程序、ApplicationFrameHost、WebView2、崩溃处理进程，不再将宿主进程当作用户后台应用显示。此列表仍不等于 Windows 全部托盘图标；第三方真实图标菜单使用原生任务栏入口。

后台图标点击只尝试恢复已有实例，不主动重新启动已退出的进程。无法安全识别主窗口或权限不足时仍提示使用原生托盘。原生快捷设置的位置、内容和显示行为由 Windows 管理，未强制移动其弹窗。

开发自验：仅人工审阅改动、生命周期保护、异步回调及恢复/启动分支，未执行自动验证。用户验收待进行：二级栏比例、不同缩放比例、后台发现与退出、微信托盘恢复、状态区统一悬浮、电量显示、Win+A 原生弹窗、两层显隐。未生成 1.9.1 包，桌面旧 1.9.0 包保持原样。
