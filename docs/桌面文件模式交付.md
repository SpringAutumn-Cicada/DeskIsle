# 0.7.0 桌面文件模式交付

## 已实现行为

- 实际Windows DesktopDirectory及其普通子目录为唯一卡片业务文件范围。外部文件/目录复制导入，原件保留；桌面已有项目加入分组，不重新复制。跨卡片空白拖放加入分组，外部/跨卡片中央文件夹投放为复制，同一卡片中央投放为确认后移动。
- TXT/MD/DOCX/XLSX/PDF/PPTX/文件夹新建固定到桌面根目录；移除更改位置、浏览任意目录及任意重新定位入口。打开、删除、拖出上传和文件同步均检查桌面边界；不显示旧外部路径、私有恢复目录或reparse路径。
- 独立深色圆角冲突框展示两侧路径、类型/文件字节数及修改时间。文件可覆盖/跳过/取消；目录可合并/跳过/取消，内部文件另询问；类型不同时禁止替换。默认跳过，应用后续同类冲突默认不勾选，选择只作用于当前批次。
- 覆盖不截断旧目标：复制来源到同卷暂存，复制期间拒绝来源写入/删除，校对长度并刷盘；大文件复制前先处理已有冲突，目标变化后重新询问，File.Replace提交并保留.backup和原目标JSON。没有删除旧目标再复制的回退。
- 所有传输串行、后台IO；进度窗显示当前路径/字节进度，可取消。已提交项目不回滚，未提交的应用暂存文件清理；成功后自动关闭进度窗、在卡片显示数量；取消或失败时保留完成页及失败明细。计数包含已完成文件及目录。内部无冲突文件移动走同卷快速重命名；目录合并只在成功且为空后删除源目录，不递归删除部分失败来源。
- 新建先生成应用自有草稿再经同一导入服务提交，因此手工输入已存在名称也出现覆盖/跳过；草稿仅属于应用，取消后清理。
- 外部重命名事件会在检查新路径仍在桌面、原路径已消失后更新分组。文件删除与原位还原沿用事件同步和30秒兜底。

## 升级迁移与恢复

配置schema3读取兼容schema2；升级前的外部References不删除，进入待迁移清单。首次提示前备份原配置到LocalAppData下cards.before-desktop-时间-UUID.json；待迁移项保持在按钮/菜单中，可导入或只移除记录。暂不处理后不反复启动弹窗，仍可菜单操作。配置保护模式拒绝导入/移动。

每个成功项保存来源→桌面映射和配置，按父路径先处理；同时引用目录及子文件时不会重复导入。文件夹部分成功时保留原待迁移项，并允许查看已落地桌面部分；下次跳过已成功映射项继续。失效/拒绝访问/链接来源列为失败，不造空文件、不删除原件。

桌面隐藏`.DeskIsle-data`保存操作日志和可恢复旧目标，目录必须含本应用所有权标记，重名占用则拒绝使用，不改动用户已有同名目录。它不作为卡片内容。恢复文件使用进度窗“恢复文件目录”，查看.backup同名JSON中的Target字段，再在退出应用后人工恢复；没有一键恢复入口或自动清理策略。不要在仍需历史版本时删除它。

## 风险与限制

- 本轮开发没有操作用户业务文件；实际复制/覆盖/迁移由用户启动新版并确认后才发生。
- 不支持符号链接、目录联接及带reparse标记的云盘项目（含部分已下载云盘文件）；Windows返回的桌面根本身作为可信入口。普通.lnk仅复制快捷方式本身，不复制其指向内容。
- 覆盖依赖Windows同卷File.Replace支持，不支持时报告失败，不做破坏性回退。检查不能保证抵御其他进程恶意改路径的竞态；应避免同时使用其他工具修改正在传输的项目。
- 批量合并不具备整批事务性，中途取消/失败保留已完成部分。进程被强制结束可能留下暂存/恢复材料和未加入分组的桌面文件；可按日志检查。配置写入失败保留桌面副本与旧配置备份，并报告错误，不反向移动已完成文件。
- 暂不支持虚拟拖放流（无FileDrop路径）、多项内部选择拖动、自动恢复备份。移动合并目录按文件处理，超大目录可能耗时。
- 不自动扫描并导入桌面全部文件；卡片是分组，仍需拖入或新建加入。
