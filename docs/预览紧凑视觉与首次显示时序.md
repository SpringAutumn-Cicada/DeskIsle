# 预览紧凑视觉与首次显示时序

版本：1.3.5；分支：test。

## 操作

- 去掉单窗及组合画面为关闭按钮预留的 22 DIP 顶栏，恢复四周约 4 DIP 内容边框，按源画面比例显示。
- 关闭按钮覆盖右上角，内缩 4 DIP；点击区域 22 DIP，叉号 10 DIP。默认隐藏，鼠标进入相应单窗或组合组后出现，离开后隐藏；常态深色底约 88% 不透明度，按钮悬停为不透明红色，取消独立描边。画面层仍保持非分层窗口，仅关闭按钮使用透明度窗口。
- 默认与悬停边框改为克制的深蓝灰，取消大块浅蓝背景；组合两窗同步反馈。内容保持比例，宽画面限宽，同排垂直居中。
- 预览改为手动固定尺寸：先测量内容，再排列、定位并准备隐藏的原生缩略图；Loaded 后在 Render 优先级一次呈现。使用预定 Width/Height 定位，避免依赖尚未稳定的 ActualWidth/ActualHeight。翻页及窗口增删仍复用已有原生缩略图。
- 对预览父窗口、画面窗口和关闭按钮分别设置 DWMWA_TRANSITIONS_FORCEDISABLED，关闭自身系统显示过渡，不修改全局动画设置，不增加滑入动画。

API 依据：[微软窗口过渡说明](https://devblogs.microsoft.com/oldnewthing/20121003-00/?p=6423)、[SetLayeredWindowAttributes](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setlayeredwindowattributes)。
