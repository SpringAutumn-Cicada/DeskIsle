# 0.7.1 简洁卡片与直接移入

## 行为

按用户最新要求覆盖此前的“移动前始终确认”：拖到同一卡片文件夹中央，无同名时直接后台移动，不显示MoveConfirmation或普通进度弹窗；仍执行桌面边界、自身/子目录、路径有效性等预检。只有同名项目弹覆盖/合并/跳过/取消窗口。错误/主动取消保留结果反馈，不静默吞掉失败。

移入长任务可从卡片更多菜单“查看当前文件操作…”主动打开进度和取消入口；不会主动抢出进度窗口。外部复制导入/新建复用的传输服务异步执行，超过350ms才显示进度，快速成功不闪窗；冲突窗口期间暂停延迟计时，避免进度窗覆盖冲突选择。任务仍串行并保留关闭保护、日志、覆盖恢复副本及引用同步。

卡片正常展示仅标题/菜单/文件：移除完成、跳过、失败数量和剩余迁移统计；取消常驻迁移条、空卡片说明及外部拖入说明。旧记录数量及入口只在菜单显示；首次迁移审阅及实际错误仍反馈。不改变文件大小、图标布局和透明度。

## 文件与边界

变更：MainWindow.Move.cs、MainWindow.Import.cs、MainWindow.NewItem.cs、MainWindow.xaml/.cs、MainWindow.FileSync.cs、TransferProgressWindow.xaml.cs、DeskIsle.csproj、README、docs/plans/quiet-move及本文。原MoveConfirmation资源保留但不再调用；FileTransfer真实写入/覆盖策略不改。未修改用户文件、配置、快捷方式及Office/PDF模板。

开发仅代码审阅及授权构建/发布/ZIP完整性和复制校验；未运行测试、浏览器或Windows交互验收，未执行实际文件移动。用户可用临时文件检查无冲突直接移入、同名选择、普通排序、菜单进度取消和卡片无统计说明。
