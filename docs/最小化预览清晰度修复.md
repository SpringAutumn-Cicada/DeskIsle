# 2.1.7 最小化预览清晰度修复

- test 基于408cf24，工作区干净；已核对近期提交、WindowPeek历史、AGENTS及项目SDK/依赖。
- 用户日志显示192DPI系统指标推导13px而正常实测11px，移除该推导。继续优先使用最小化前完整几何缓存。
- 源尺寸不匹配时取消按目标大小等比重采样；源矩形和目标矩形保持相同像素尺寸，仅调整本地画面层尺寸，真实源窗口不展开、不移动。

- 诊断在最终本地图层定位后记录，避免原先记录缩放前的目标矩形；reliable仍表示原始尺寸匹配，不代表未知缓存已获证实。
- 无法从DWM恢复源应用未提供的像素；本次去除我们额外缩放造成的模糊，缓存本身低分辨率或过期画面仍可能存在。未知尺寸时预览视觉大小可能与原窗不同。
