# DeskIsle 1.2.4

- 原生画面和WPF面板停留判断统一：任何画面内的鼠标都算预览内部，收起计时不再只依赖父窗口范围。
- 原生画面返回HTCLIENT，按下捕获鼠标，释放时检查仍在画面区域再执行操作；单窗激活前关闭预览并同步恢复最小化窗口，避免预览顶层遮住目标。
- 不使用一次性shown标记，检查真实原生可见状态，避免被系统隐藏后永久不再显示。
- 左右组合识别允许20%～80%分隔位置以及按屏幕尺寸容忍边框，仍要求同屏同应用、互补全高布局；不等同系统原生Snap Group。会话未观察到布局/无法读取应用身份时不保证组合出现。
- 蓝灰边框加粗为3个物理像素，仍不缩放、不改变内容透明度。
- 修改WindowThumbnail.cs、WindowPreview.cs、DockWindow.xaml.cs、SplitGroups.cs、版本和README；用户配置和真实文件未改。

读取Windows现有1026事件仅找到此前已修复的PresentationSource初始化堆栈，没有据此宣称当前点击故障已实测定位。本轮未执行自动化测试、lint、独立类型检查或Windows交互验收。

待用户验证：鼠标停在单窗与组合预览持续显示、点击各独立窗口可激活、组合显示并恢复、比例分屏、切换应用和离开后收起；源画面受DWM缓存或保护限制时仍可能无内容。
