# 菜单动画与预览显隐修复

版本 1.3.4，分支 test。

## 操作

- 开始菜单：忽略 DWM cloaked 窗口，打开至少 500 毫秒且窗口边界稳定 250 毫秒后才请求调整。保留 12 DIP 间距，约束左右边界，避免贴边裁切。定位后重新读取实际窗口矩形；仍保留八次调整上限及异步跨进程定位，不阻塞 Dock。此调整修正上一版动画期间过早耗尽尝试的问题，不能保证所有 Windows Shell 版本接受位置或尺寸请求。
- 预览停留：全屏检测不再抢先关闭正在交互的 Dock/预览；预览正在交互时，后台枚举漏掉但句柄尚存的窗口继续保留。鼠标一直停在图标上、窗口列表随后补齐时，重新安排预览打开。
- 预览恢复：从 Loaded 开始统一观察，不依赖首次 ContentRendered；首次打开只检查句柄存活，不因临时不可见剔除。缩略图三次失败后冷却三秒再允许新一轮三次尝试，防止一次暂时失败导致本次悬停永久只显示图标。
- 关闭按钮：贴缩略图最右上角、取消内缩和独立圆角描边；默认底色与缩略图边框一致，悬停红色。为关闭按钮保留 22 DIP 顶边内容区域，避免盖住窗口内容；单窗内容尺寸相应增加，保持画面比例。
