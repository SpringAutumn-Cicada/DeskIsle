# 2.0.7 默认卡片与分组转移

- 分支 test，基于 5c62e3c，开始前工作区干净；已检查近期提交、相关文件历史，专用 SDK 与依赖已安装。
- 卡片外观新增“恢复默认不透明度（85%）”，与新卡片使用同一默认常量，沿用实时显示与保存。
- 工作区单个 DefaultCardId 维护唯一 default：旧配置首次指定第一张卡片，菜单可切换，菜单勾选表明当前 default；移除默认卡片自动选择剩余第一张，不允许通过取消勾选变为无默认。最后一张移除后按原流程退出。
- 持久化桌面可见项目快照，首次升级建立基线不重分已有桌面；其后新增且未属于其他卡片的项目加入当前 default，重启可对比快照收纳离线新增项目。桌面 watcher 触发同步，30 秒轮询兜底；并发扫描合并，文件操作/拖动时暂缓，保存失败回滚分组与快照。
- 仅处理实际用户桌面根目录、符合既有展示规则的文件和文件夹，不递归收纳子项，不收纳隐藏/系统/内部恢复目录及不支持的链接。新增但已归入其他卡片的项目不重复分配。
- 不移动或复制桌面真实文件；用户手动移除分组引用不会在下一次扫描被重新加入；切换 default 不搬迁已有归属。
- 跨卡片内部拖动桌面项目转移分组引用：保存成功才刷新视图，来源移除、目标增加；失败回滚。拖入文件夹使用原有确认移动流程；向浏览器等外部目标仍保持既有 Copy 传输行为。
- 版本 2.0.7；功能提交 e43db9a、e47a322、92c49b9。未运行测试、lint、独立类型检查、浏览器或 Windows 交互验收。
- 用户验收待进行：重置85%及重启保存、默认切换唯一性、移除默认自动接替、新建/下载/离线新增收纳、桌面重命名、跨卡片转移与取消/失败回滚、拖入文件夹和外部上传。
