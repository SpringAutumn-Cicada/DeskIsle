# A2 控制中心视觉与点击切换

基于 1566bdc，分支 test；开始工作区干净，项目 SDK 已安装，已审阅相关文件历史。

第一项修复：WPF Popup 在 StaysOpen=false 时会在外部鼠标按下阶段关闭，而 Dock 的 Button.Click 稍后执行，导致同一手势将其重新打开。关闭时只记录“左键按下且位于状态入口内”的手势，点击消费该记录，不重新打开。正常点击入口仍打开，已打开时再次点击关闭；点击外部沿用原关闭行为。旧 Popup 的 Closed 回调不再清理新 Popup 的页面。

仅人工源码审阅，未运行测试、lint、独立类型检查或 Windows/浏览器交互验收。最终发布按持续授权自动打包至 Windows 桌面，构建不等于功能验收。
