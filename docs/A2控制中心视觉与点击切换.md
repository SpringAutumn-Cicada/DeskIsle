# A2 控制中心视觉与点击切换

基于 1566bdc，分支 test；开始工作区干净，项目 SDK 已安装，已审阅相关文件历史。

第一项修复：WPF Popup 在 StaysOpen=false 时会在外部鼠标按下阶段关闭，而 Dock 的 Button.Click 稍后执行，导致同一手势将其重新打开。关闭时只记录“左键按下且位于状态入口内”的手势，点击消费该记录，不重新打开。正常点击入口仍打开，已打开时再次点击关闭；点击外部沿用原关闭行为。旧 Popup 的 Closed 回调不再清理新 Popup 的页面。

仅人工源码审阅，未运行测试、lint、独立类型检查或 Windows/浏览器交互验收。最终发布按持续授权自动打包至 Windows 桌面，构建不等于功能验收。

第二项美化（1.11.1）：无线按钮改为连接的左右圆角分段，共用真实状态底色，名称与次级状态内置；克制冰蓝色代替大面积高饱和蓝。控制卡统一细边框、18 DIP 圆角、内边距和轻阴影。音量使用矢量扬声器、4 DIP 圆角轨道、圆形滑块及悬停反馈，保留拖动/点选轨道和键盘操作。工具区取消大色块，使用轻量图标与次级文字。详情列表统一图标、单行截断名称、状态和箭头；入口打开时保持短光条提示。保留既有 Dock 风格与所有无线/音量行为，不添加后台应用或弹窗电池卡。

用户待验收：再次点击入口关闭、点击外部关闭、快速开关与详情返回、轨道点击/拖动/键盘、无线开关与设备列表、高 DPI 清晰度。未执行功能测试或 Windows 交互验收，发布校验后追加结果。
