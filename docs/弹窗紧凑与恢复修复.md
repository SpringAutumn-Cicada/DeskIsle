# 0.5.5 弹窗紧凑与恢复修复

新建弹窗从400×360 DIP调整为420×280 DIP，与删除弹窗同宽、同深色背景、22 DIP内边距，去除大面积空白和半透明透底；仍独立于卡片尺寸，表单滚动、操作区固定。删除确认与新建弹窗默认屏幕居中（Windows CenterScreen定位），不再贴近卡片。

代码发现两个延迟风险：原新建逻辑在显示窗口前等待目录名称检查；桌面恢复逻辑仅处理卡片，未包含其独立弹窗。现在先绘制新建窗口，再异步准备不重名名称；窗口显示后将焦点放入名称。新建、删除确认均注册到卡片恢复路径，Win+D返回桌面的事件恢复会处理仍打开的弹窗；关闭即注销，不设始终置顶，不激活抢焦点，不恢复已关闭窗口。Windows通知、DWM及目录IO仍可能造成延迟，未测量实际显示时延。

本轮未执行自动化、视觉或Windows交互测试。待用户验收：Win+D后弹窗恢复、首次/重复新建、长路径与高DPI、删除居中、取消和确认；未对真实文件执行删除。
