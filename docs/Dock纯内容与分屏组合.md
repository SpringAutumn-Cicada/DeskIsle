# DeskIsle 1.2.0

## 行为

- 固定、取消固定或排序在菜单/拖动结束后补刷；并发刷新请求排队，不依赖打开新应用。快捷方式后台解析完成后显示固定项。
- 预览期间继续同步窗口列表，不再因预览打开而丢弃全部更新。每个原生画面直接处理自己的点击，不依赖点击穿透到WPF；鼠标释放后在UI队列激活明确窗口。
- 纯内容预览无标题、窗口数量、说明文字或不可见关闭热区，按原窗口比例缩放到最大250×156 DIP，边框贴合；画面不可用时仅图标。窗口关闭仍可从Dock右键菜单操作。
- 相同应用（包括Edge）在同一屏幕构成左右两个全高半屏布局时，增加左右组合预览，单窗口预览保留。组合点击恢复两已有窗口和记录的矩形。仅会话内记录已观察布局；不推测任意两个窗口，不声称使用系统原生Snap Group，不跨屏强行组合。
- 最小化后仍可用已记录分屏位置；关闭、明显改布局、换屏不再匹配原组合。重启后需先观察非最小化窗口布局才能识别。
- 用户配置、真实文件、卡片文件操作和当前Windows窗口未改。

## 文件

DockController.cs刷新排队；DockWindow.xaml.cs交互结束补刷和预览同步；WindowThumbnail.cs原生点击；WindowPreview.cs纯内容；SplitGroups.cs布局识别与恢复；项目版本和README。

## Windows待验收

1. 右键固定后菜单关闭立即出现固定项，退出所有窗口及重启仍保留。
2. Edge两个窗口预览可分别点击到各自窗口；保持面板期间关闭/新建窗口有同步。
3. 预览无说明和标题，横竖窗口按比例，画面无额外大面积占位。
4. 将两个Edge左右贴靠，出现组合项；切到其他应用或最小化后点击组合，两窗口回到原左右位置。单个预览只激活单个窗口。
5. 改布局、关闭其中一个、切换屏幕后组合不过期；开始菜单、最小化、排序、全屏和底边唤出回归。

本轮不执行自动化测试、lint、独立类型检查或Windows交互验收，只执行交付构建和ZIP/副本校验；原生画面和窗口激活可能受系统权限、受保护内容及DWM缓存限制，尚待验收。
