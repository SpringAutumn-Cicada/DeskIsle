# 1.9.3 居中简洁面板与微信启动激活

分支 test，基于 ce7504c；开始工作区干净，项目 SDK 已安装。

后台面板去掉标题和完整原生托盘按钮，只保留居中的应用图标；宽度按数量收缩，最多五列。图标为 28 DIP，单独按 DPI 提取至少 96 像素图像，避免复用主栏低尺寸缓存；采用布局像素对齐和高质量缩放。弹窗通过自定义位置相对箭头居中，屏幕边界仍由 WPF 处理。

移除自动切换原生任务栏和 UI Automation 托盘扫描。微信后台恢复改为通过已验证路径启动微信自身入口，让其单实例启动逻辑处理激活；最多观察三秒，发现可见且启用的同路径窗口后激活。既不强制显示隐藏窗口，也不改变原生/Dock 模式。重复点击合并，切换模式/退出取消观察。不同微信版本可能忽略激活或弹登录入口，此兼容性待用户实测，不承诺所有版本均支持；失败明确提示，不切走 Dock。

只做源码人工审阅，未执行测试、lint、独立类型检查、Windows/浏览器交互验收。按持续授权自动发布新包至 Windows 桌面；发布与复制校验结果追加。
