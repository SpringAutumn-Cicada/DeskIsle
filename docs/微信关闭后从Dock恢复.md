# 1.9.5 微信关闭后从 Dock 恢复

分支 test，基于 a8e1522；开始工作区干净。恢复图标与预览点击共用后台恢复路径，修复 1.9.4 隐藏预览点击直接返回、应用点击只显示预览的问题。

后台微信不启动可执行程序，不强制显示隐藏主窗口。临时让真实任务栏可访问，在 MTA 工作线程定位 Explorer 中限定名称的微信托盘按钮；需要时展开隐藏图标。优先对实际可点击位置执行真实双击，兼容没有 InvokePattern 的 Win11 托盘按钮；无法获取位置时尝试 InvokePattern。真实双击会短暂移动指针，操作后若用户未移动指针则恢复原位，不干预用户新位置。

临时托盘访问不会切换 NativeMode，不显示返回 Dock 按钮，所有成功、失败和取消路径均恢复任务栏隐藏策略及 Dock。操作期间暂停 Dock 自动显隐，避免遮挡托盘按钮；用户切换模式或退出取消后续操作。工作槽限制一个 UIA 操作，等待限制两秒，匹配容器和名称受限；不修改系统或微信配置。

只有观察到同路径可见且启用主窗口才报告恢复，失败提示原因，不创建新实例。系统版本、语言或权限导致无法定位托盘图标时仍可能失败，须由用户实测；未将源码修复或发布成功记为微信功能验收通过。
