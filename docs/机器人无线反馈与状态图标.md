# 1.11.23 机器人、无线反馈与状态图标

- test 分支，基于 0d142d1；核对中断后工作区干净，未重复执行修改或发布。项目专用 SDK 已安装。
- 原生任务栏工具键采用返回机器人的共享矢量；返回机器人移除会栅格化的阴影效果，取消图案布局取整与像素吸附，保留深浅对比轮廓和造型。拖动、点击及焦点逻辑不变。
- 无线卡由 108 降至 98 DIP，图文间距收紧，开关向内、向下调整。Wi-Fi 扇形展开角度加大；Dock 音量与电池描边加粗，电池正常为绿色、低电量橙色、未知灰色，并加轻微绿色底。
- 无线操作先显示处理中并提交渲染，再调用系统 API；移除固定 250ms 等待，仅在状态未达目标时短间隔重读。快速开关结果先更新，再核对连接状态，避免蓝牙连接枚举拖延开关反馈。旧异步刷新用修订号隔离，禁止覆盖本次操作状态。不把处理中伪报为连接成功。
- Windows 无线硬件和系统实际切换时间仍存在，不能保证瞬时完成。
- 未运行测试、lint、独立类型检查或 Windows 交互验收；仅执行授权发布构建与包完整性/复制校验。
- 待验收：机器人深浅背景抗锯齿、工具入口正确、无线开关反馈与权限失败、卡片紧凑比例、满/低电量颜色与高音量完整性。
