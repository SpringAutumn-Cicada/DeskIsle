# DeskIsle 1.0.1 Dock 清晰度与交互修复

## 行为

- 启动程序自动开启 Dock，包括旧配置 Enabled=false 的情况。本次设置停用仍有效，下次启动重新开启；未知版本、损坏配置和接管失败仍保持保护，不强行隐藏任务栏。
- 固定区按用户排序，运行区按本次会话首次出现的应用组排序，新组追加。打开/激活/切换窗口不按 Z-order 重排，关闭应用正常移除；Dock 总宽度变化时仍保持居中。
- 不再把32像素小图标先放大成64像素。优先按屏幕缩放请求96～256像素 Shell 图标，并用高质量采样显示。DPI变化清除对应缓存；系统按钮用矢量路径，布局像素对齐。
- 无法读取 EXE 图标时尝试窗口图标，减少通用占位；来源仅提供小图时仍受原素材清晰度限制，不伪称所有应用都具备高清源图。
- 设置页改为无系统标题栏的深色圆角窗口，自定义开关和滑块、实时数值、快捷键字母输入、保存与取消。小工作区内容可滚动，Escape取消，标题可拖动。

## 修改范围

`DockApps.cs` 图标提取与句柄释放；`DockWindow.xaml`/`.xaml.cs` 渲染和运行区稳定排序；`DockSettingsWindow.xaml`/`.cs` 设置界面；`DockStore.cs`/`DockController.cs` 启动行为；项目版本与README说明。

未直接修改用户配置或任务栏状态，未关闭正在运行的旧版；卡片文件传输、删除、新建逻辑未改。

## 实现依据

[微软 IShellItemImageFactory.GetImage 文档](https://learn.microsoft.com/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishellitemimagefactory-getimage)：后台提取仅图标，允许返回更大原图；调用方释放HBITMAP。不读取文件内容缩略图。
