# 1.11.2 控制中心 B 细线玻璃

分支 test，基于 2d6ffec。工作开始时 Git 干净；已核对布局及样式历史，项目 SDK 已安装。保留原有主 Dock 图标顺序与功能，不改全局配置。

弹窗使用一体绘制的圆角气泡及小尖角，水平中心对准状态组合入口中心，尖角尖端与入口上缘保留 18 DIP 间距。屏幕左右空间不足时限制面板位置，调整尖角横坐标，避免整个弹窗越出主屏。圆角限制范围内尖角尽量对准入口；不同屏幕缩放及极窄屏待用户验收。

音量使用统一生成的矢量几何：静音或 0% 显示叉号；1–33% 一条声波，34–66% 两条，67–100% 三条。弹窗及 Dock 同步，静音优先且不修改之前音量值。

B 视觉：减淡无线卡色块，细描边、左右连续圆角、细竖线区分开关与详情；音量区透明浅底和细线；工具键采用圆角小窗口、平滑心电线及圆润齿轮图标，图标与文字横排。保留再次点击关闭和外侧点击关闭、系统状态同步及详情页功能。没有添加后台应用或弹窗电池卡。

开发自验仅人工源码审阅，未运行测试、lint、独立类型检查或 Windows/浏览器交互验收。最终按持续授权发布桌面包并验证完整性，不能将发布成功记为视觉/功能验收通过。
