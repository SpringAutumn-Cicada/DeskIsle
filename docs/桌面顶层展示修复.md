# 0.7.2 桌面顶层展示修复

卡片是桌面直接子项的分组，不是桌面目录树的文件集合。

- 文件或文件夹移入桌面上的文件夹后，不再单独出现在任何卡片；目标文件夹保留。
- 加载、事件同步和重启均过滤内部文件；保存配置时移除旧内部引用，不删除或移动真实文件。
- 外部文件导入桌面根目录后可以显示；直接导入文件夹的内容不再额外显示在卡片顶层。
- 桌面子目录中的文件拖到卡片空白处不会添加引用或复制到桌面根目录。
- 普通隐藏和系统项目不展示；用户主动隐藏整个 Windows 桌面图标视图，不影响卡片展示。
- 外部待迁移记录及暂不可用的顶层记录保留；卡片仍按用户分组展示，不自动加入所有桌面项目。

## 用户验收待执行

1. 同一文件引用在两张卡片上，移入文件夹后两张卡片均不再显示，目标文件仍存在。
2. 重启后旧内部引用不再出现；文件夹仍可打开，内部文件可访问。
3. 从外部向卡片空白处导入，出现在桌面根目录；向文件夹导入，仅出现在目标文件夹内。
4. 在资源管理器外部移动桌面文件进文件夹，卡片同步移除原位置项目。
