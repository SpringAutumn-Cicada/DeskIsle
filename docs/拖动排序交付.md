# 0.4.0 卡片内拖动排序

## 实现

- 按住文件或文件夹图标，移动超过系统拖动阈值后开始拖动；释放插入到目标项之前/之后。拖动期间源图标降低透明度，显示带图标和名称的悬浮预览、青绿色插入线和目标高亮。靠近上下边缘时缓慢自动滚动；Esc取消，离开卡片或取消后清除预览。
- 只交换卡片内的显示顺序，不修改真实文件位置、内容或属性。内部拖动采用专用数据格式，不向系统提供FileDrop，不会触发真实文件移动。
- 收藏模式保存References顺序；目录浏览模式单独保存按目录区分的显示顺序，新增文件继续按原排序追加，刷新后保留手动排序。原有外部文件拖入收藏保持不变。
- 重排后保持滚动位置，不自动居中。单击和双击仍沿用原行为，拖动结束短暂抑制误触打开。不同卡片之间本轮不做拖动转移，目标卡片显示禁止放置，不改变两张卡片内容。

## 变更范围

MainWindow.Reorder.cs封装内部拖动、落点计算、边缘滚动和顺序保存；Services/ReorderAdorner.cs绘制矢量拖动反馈；MainWindow事件区分内部排序与外部引用拖入；CardState和WorkspaceStore兼容保存目录手动顺序。原卡片配置、标题和收藏保留。

## 验证与待用户验收

按项目规则仅执行交付所需构建发布和包完整性/复制哈希校验，不主动运行自动测试或Windows交互验证。结果在发布后追加。

待Windows验收：同一行前后移动、跨行、首尾位置、末行空白、拖回原位、Esc取消、拖出卡片、快速双击打开、拖动结束不误开；大目录上下边缘滚动及取消后停止；重启/刷新顺序恢复；外部文件拖入和多卡片各自排序不受影响；不同DPI下插入线与图标对齐。

边界：采用网格插入排序，不提供任意像素位置的自由摆放，也不实现跨卡片转移或真实文件移动。既有桌面嵌入兼容限制仍在。
