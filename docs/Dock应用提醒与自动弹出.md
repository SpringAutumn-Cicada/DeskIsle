# Dock 应用提醒与自动弹出

版本 1.5.0；分支 test。

接入 RegisterShellHookWindow 的 SHELLHOOK/HSHELL_FLASH 系统窗口提醒。按现有应用组映射对应窗口，图标后方使用橙色柔和呼吸底色，底部点变橙；不改变图标位置、尺寸，不读取聊天内容或未读数量。

Dock 隐藏时提醒会不抢焦点地自动展示约五秒，即使前台全屏也在这五秒内尝试置顶展示。五秒内同应用重复信号合并；展示到期继续按现有鼠标停留、离开延时及桌面/全屏规则处理。收起后保留橙色提醒，激活对应窗口或同应用组窗口后清除。源窗口销毁时清理状态；退出或禁用 Dock 注销 Shell 监听、清除计时及动画。

用户手动切到原生任务栏时不强行改变原生模式，后台保留 Dock 提醒，返回 Dock 后可见。普通窗口重绘不当作提醒。注册监听失败会明确提示，基础 Dock 功能继续可用。

实现依据：[微软 RegisterShellHookWindow 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registershellhookwindow)。此接口属于 Shell 通知机制，并非每种消息通知都会产生此信号；仅托盘变化或系统通知的应用可能无法触发。新窗口需经现有枚举归入应用组才显示提醒。独占全屏等场景即使置顶请求成功也不保证覆盖源应用。
