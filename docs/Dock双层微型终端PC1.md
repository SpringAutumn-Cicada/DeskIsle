# PC1 双层 Dock

版本 1.9.0，分支 test。基于 3820c98 实施，开始时工作区干净。

## 操作与行为

- 主栏保持左侧 HH:mm、单排应用、最右侧显示桌面；显示桌面使用原始显示器符号及青色角标。
- 上层居中微型终端使用深色面板、冰蓝矢量图标、细光带、状态灯和短支架。依次为原生任务栏、任务管理器、设置、后台应用、网络、音量、电量。
- 两层位于同一透明窗口，统一沿用淡入上移与淡出下移。中间间隙纳入鼠标停留范围；弹出面板打开时保持显示。预览位于上层终端上方，切换原生模式同时隐藏两层。
- 网络每两秒读取已启用适配器，优先有网关的连接，区分无线、有线和未连接；点击进入系统网络设置。不将适配器已连接等同于已接入互联网。
- 音量使用当前默认输出设备的 Core Audio 接口，支持滑条、静音及声音设置入口；状态每两秒更新。设备不可用时明确提示。
- 电量使用 GetSystemPowerStatus，显示真实百分比及充电提示，无电池时收起；无法读取时显示横线，不伪造数值。
- 普通点击固定应用优先识别同路径运行进程及之前识别到的主窗口；微信额外识别已重建的特定主窗口。已有后台进程但无法确认主窗口时，不重复启动，提示使用原生托盘。右键“打开新窗口”仍可主动启动。
- 后台面板仅列出已固定或本次会话识别过的应用中仍在运行且没有可见窗口的项目；提供切换原生任务栏入口，用户可操作完整托盘。没有复制第三方托盘图标回调或菜单。
- 异步读取和恢复返回后检查控制器/窗口生命周期，重复点击按应用合并；已关闭的设备和窗口不保留长期 COM 引用。
