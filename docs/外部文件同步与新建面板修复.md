# 0.5.2 外部文件同步与新建面板修复

## 外部文件变化

原实现仅在加载/手动刷新时读文件。现在卡片使用2秒后台同步，正常可访问目录内被桌面/资源管理器删除的项目自动隐藏；浏览目录同步新增及删除。相同父目录每轮只枚举一次，单卡片最多一个同步任务，低优先级调度，不在界面线程执行目录IO；内容不变不重建界面，拖动、加载及文件操作期间跳过。异步结果带视图版本校验，关闭后忽略结果并停止定时器。

仅父目录成功枚举后确认不存在才隐藏收藏项目；离线或无权限保留不可用引用。收藏配置保留原路径，文件还原到原路径后重新显示；同步不移动、不删除真实文件，不自动将桌面所有新文件加入收藏。每卡片轮询而非实时监听；慢速/网络目录可能超过两秒，界面忙碌时延后同步。暂未追踪外部重命名的新路径。

开发自验：代码审阅；本轮未运行自动化测试或Windows交互验收。用户验收待确认：外部删除、多卡片、回收站原位还原、离线目录、目录视图增删及拖动期间同步。

## 新建面板

原按钮位于滚动内容底部，短卡片或长路径时不可见。现在创建/取消固定在面板底部，表单单独滚动；输入框改为圆角、布局填满可用区域。文件夹、TXT、Markdown共用修复，不改变创建目标及同名保护。Windows缩放和最小尺寸交互仍待验收。
