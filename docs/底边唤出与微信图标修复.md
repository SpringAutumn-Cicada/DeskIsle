# 底边唤出与微信图标修复

版本 1.5.2；分支 test。

## 发现与修改

现有全屏分支在底边命中检测前直接返回，导致全屏或被判定全屏的应用下无法通过底边唤出。改为先判断底边停留，在全屏下也响应明确的鼠标唤出；鼠标进入 Dock/预览继续保持，离开交互区域后全屏规则仍可隐藏。底边唤出后每 500 毫秒重申显示和无激活置顶，修复窗口被外部最小化或覆盖后，鼠标不离开底边便无法再次触发的问题；不每个 80 毫秒轮询都调用显示。

只读检查 Windows 进程及 Dock 固定项：Weixin 仍运行，存在主窗口，固定项为 `D:\Normal\Weixin\Weixin.exe`。用户截图中原位置显示通用文档图标，固定记录未丢失；Shell 图标返回与缓存是需处理的疑点，未通过图标实际提取复现证明唯一根因。

针对 Weixin.exe/WeChat.exe 优先从可执行文件资源提取指定尺寸图标，避免 Shell 通用图标或窗口通知动态图标影响。其他应用保持现有提取顺序。提取出来的 HICON 在冻结复制后释放；接口不可用或失败时退回原有 Shell 流程。依据：[微软 PrivateExtractIconsW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-privateextracticonsw)。此接口兼容性有系统限制，已保留后备路径。

图标提取失败不再把 null 放入缓存，三秒后允许重试；已有有效图像时保留，避免一次短暂失败使本次运行永久停留空图。未改动用户固定配置、SDK 或全局设置。
