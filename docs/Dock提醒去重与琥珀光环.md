# Dock 提醒去重与琥珀光环

版本 1.5.1；分支 test。

## 行为修复

将自动弹出从“每五秒可以再次触发”改为“每轮应用提醒只触发一次”。以应用可执行路径归并窗口，枚举未补齐时尝试获取进程路径，无法获取才使用进程 ID；为每个提醒窗口保存本轮归属，避免窗口列表变化导致重复弹出。同一轮后续闪烁不修改五秒期限，也不调用 Reveal。激活应用或相关提醒窗口全部销毁后清除本轮状态，下一轮才可再弹出。

五秒结束后恢复现有显隐规则：鼠标停留或预览交互保持，离开后按设置收起；无未最小化应用窗口时仍按原产品行为常驻桌面。手动原生任务栏模式不被强制切换。不同应用首次提醒仍可发起自己的五秒展示。

## 视觉

使用 1.5 DIP 琥珀色圆角光环，颜色 #FFB950，轻微柔光与低透明度底色；图标保持原色和位置。前五秒以约 1.6 秒周期、0.4～1 不透明度呼吸，之后转成约 2.4 秒周期、0.2～0.5 的低强度提示。底部状态点变为 10×3 DIP 橙色短横条。整条 Dock 不染色、不跳动，动画仅在提醒状态或强度阶段变化时重建。
