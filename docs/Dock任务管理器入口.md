# Dock 任务管理器入口

版本 1.5.5；分支 test。

在 Dock 设置按钮紧邻左侧增加任务管理器按钮，使用与现有工具按钮一致的 23 DIP 浅色线条图标、40×48 DIP 点击区域，以及“任务管理器”提示和无障碍名称。点击先收起窗口预览，再通过系统目录的 Taskmgr.exe 打开任务管理器；使用现有应用启动及错误提示流程，不指定额外提权，不修改用户设置。同步为新按钮增加应用滚动区的工具栏宽度预留。

开发自验：开始前工作区干净，核对近期提交及相关文件历史，专用 SDK 已安装，完成代码审阅。未执行测试、lint、独立类型检查或 Windows 交互验收，未实际打开任务管理器。最终发布及包校验记录见下方。

用户验收待执行：按钮位置、图标与提示、点击打开系统任务管理器、重复点击、小屏及高 DPI 工具栏布局。系统权限或策略阻止启动时由现有错误弹窗提示。
