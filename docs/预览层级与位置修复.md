# 2.0.13 预览层级与位置修复

- 分支 test，基于 f857d89，开始前工作区干净；已核对近期提交、相关实现历史和项目规则，专用 SDK、恢复依赖存在。
- 原因：临时窗口仅放到普通窗口顶部，仍可能被置顶窗口遮挡；最大化窗口临时使用工作区矩形后，点击路径没有对全部原最小化窗口重新写入保存的 placement。

- 原最小化窗口在移开或正式打开时均重新应用保存的 WINDOWPLACEMENT，包含普通还原矩形和最大化恢复标记，避免把临时工作区尺寸保留为正式打开尺寸；原已打开窗口没有几何调整。
- 开发侧仅代码审阅与授权发布；未运行测试、lint、独立类型检查或 Windows 交互验证。
