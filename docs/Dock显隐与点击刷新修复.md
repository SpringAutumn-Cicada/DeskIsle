# DeskIsle 1.0.2 Dock 显隐、点击与刷新

## 修改行为

- 没有普通应用窗口、全部关闭或全部最小化时，Dock 常驻。桌面卡片、Dock 设置和托盘后台进程不算普通应用窗口。
- 有未最小化应用窗口时才启用移开后收起；主屏全屏仍优先隐藏，手动切回原生任务栏模式仍收起 Dock。
- 点击前台应用图标最小化该窗口；单窗口应用再次点击恢复激活。多窗口应用前台属于该组时最小化该窗口，其余情况显示窗口列表供选择。
- Dock 鼠标点击不先抢走原应用前台状态；右键“切换到窗口”保持激活语义。
- 按固定项/运行应用身份复用控件，不再随前台切换或窗口标题刷新清空整个图标列表。新增、移除或用户排序时才增删/移动对应控件。
- 悬停缩放只在进入和离开时执行；图标加载按路径及DPI复用，过期结果不能覆盖新的控件状态；菜单按当前窗口数据生成。

## 文件范围

- `src/DeskIsle/Dock/DockController.cs`：空桌面常驻判断。
- `src/DeskIsle/Dock/DockWindow.xaml.cs`：不激活鼠标交互、最小化切换、控件复用和动态状态/菜单。
- `src/DeskIsle/DeskIsle.csproj`：版本 1.0.2；README 与本交付记录更新。

未修改卡片文件操作、用户配置或真实文件，未启用 Windows 交互试验。

## Windows 待验收

1. 关闭全部普通应用，移开鼠标后 Dock 保持显示；所有应用最小化时同样常驻。
2. 打开普通应用后移开鼠标，按设置延迟收起；底边可唤出。全屏和原生任务栏切换不受常驻策略干扰。
3. 同一单窗口应用反复点击图标，在最小化/恢复之间切换；其他应用在前台时先激活。
4. 多窗口组前台最小化、窗口列表选择、右键关闭窗口，行为符合说明。
5. 鼠标悬停图标至少15秒，切换前台或让窗口标题更新，无重复进出缩放；固定、取消固定、排序、DPI图标和菜单功能保留。
