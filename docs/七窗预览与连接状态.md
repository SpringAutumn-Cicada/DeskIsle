# 1.11.5 七窗预览与连接状态

- 分支：test。基于 cc7748a；开始时工作区干净。
- 预览每页最多 7 张卡片，分屏组合占一个卡位；保留组合恢复，超出分页。左右翻页按钮放在两侧垂直居中，预留独立空间避免覆盖缩略图，首尾页不可用方向淡化。预览随屏幕宽度缩放。
- Wi-Fi / 蓝牙首页显示真实连接状态“已连接 / 未连接”，不再将无线开启当作连接；无设备、策略禁用及读取失败保留异常反馈。开关由卡片底色和发光指示点体现，详情页使用电源图形。
- 底部三个工具键图标从 25 缩至 20 DIP，图文间距从 9 缩至 4 DIP，上下内边距从 12 缩至 5 DIP。
- 依赖：项目专用 Windows SDK 已安装，无全局配置修改。
- 开发验证：仅进行交付所需发布构建及包完整性校验；未运行测试、lint、独立类型检查或 Windows 交互验收。
- 用户验收待进行：7 张预览及翻页、分屏组合、无线连接变化与关闭反馈、底部工具区比例。蓝牙状态依赖系统设备枚举权限与响应；读取失败不伪报未连接。
