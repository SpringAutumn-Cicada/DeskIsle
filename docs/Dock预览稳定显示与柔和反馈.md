# DeskIsle 1.2.2

## 实现

- 隐藏状态建立窗口句柄、注册DWM关系，按实际图像比例确定宽度，测量与布局后准备目标区域。
- 移除ContentRendered中再次重建预览和刷新时动态调整宽度，避免打开后多次换尺寸。
- 原生画面仅在目标位置变化时调用SetWindowPos，首次需要显示时才调用ShowWindow，不每50ms重复显示。
- 高亮改为柔和蓝灰边框，按下边框略亮，缩略图始终不透明，不再整张发灰。组合保持共同悬停反馈，不新增文字或缩放动画。
- 保持移回同一图标不重建、单窗点击、组合恢复、固定更新和纯内容样式。

修改 WindowPreview.cs、WindowThumbnail.cs、版本与README。未修改用户配置或用户文件，未启动新版、未操作用户窗口。

## 验收边界

本轮未执行自动化测试、lint、独立类型检查或Windows交互验收。需用户验证首次预览不闪过中间画面、往返图标不刷新、单窗/组合蓝灰反馈、切换分页关闭及不同DPI。DWM来源应用刷新或保护内容的画面问题不能仅靠发布构建判定通过。
