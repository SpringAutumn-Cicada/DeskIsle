# DeskIsle 1.3.0

## 实现

- Dock单窗口直接提供「关闭窗口」，多窗口在同一层按标题列出「关闭：窗口标题」和切换入口，不再进入二级菜单。发送WM_CLOSE，保留应用保存提示，不强制结束进程。
- Dock增加显示桌面矢量按钮，发送完整Win+D键序列；再次点击由Windows切回。开始、任务栏与设置入口保留，小屏宽度预算增加新按钮空间。
- 卡片文件/文件夹增加重命名、复制、剪切、复制路径、系统属性。复制与剪切提供标准文件剪贴板及Preferred DropEffect，可到资源管理器粘贴；剪切本身不移动文件。
- 重命名采用深色圆角输入窗，取消无改动；验证保留名称/分隔符等，不覆盖同名目标。成功后同步所有卡片引用。仅改大小写目前要求先改为其他名称再修改，避免不可靠临时覆盖。
- 删除仍使用原确认与回收站流程；移出卡片只解除引用。
- 保持桌面范围及链接路径检查。用户真实文件、剪贴板和窗口未用作试验。

## 修改文件

DockWindow.xaml/.xaml.cs、DockNative.cs、MainWindow.xaml、新增MainWindow.FileActions.cs与RenameFileWindow.cs、项目版本和README。
