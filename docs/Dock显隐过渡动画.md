# Dock 显隐过渡动画

版本 1.6.0；分支 test。

整条 Dock 显示时从最终位置下方 8 DIP 上浮并淡入，180 毫秒 EaseOut；隐藏时下沉 6 DIP 并淡出，140 毫秒 EaseIn，完成后才真正隐藏窗口。仅使用整窗透明度与整块 Surface 渲染位移，图标/分隔线保持相对位置，原有背景不透明度设置仍由 Surface 独立控制。

首次显示先以透明状态准备布局、居中和原生显示位置，再播放动画，避免默认位置闪过。动画反转读取当前透明度和位移作为起点，用版本号使旧完成回调失效；隐藏过程中鼠标重新进入 Dock/预览会转为显示。底边持续停留的原生置顶恢复不重复播放已显示的动画，提醒自动弹出复用同一流程。

启用系统减少动画（ClientAreaAnimation 为 false）时直接显示/隐藏。切换到原生任务栏时立即隐藏，避免两条任务栏交叠。正常鼠标/全屏离开隐藏走淡出；退出关闭仍正常清理窗口，不延迟退出。保持开始菜单定位和预览内容/布局实现不变。

开发自验：开始前工作区干净，核对近期提交及相关文件历史，项目专用 SDK 已安装，完成代码审阅。未运行测试、lint、独立类型检查或 Windows 交互验证。按项目交付约定执行发布及包校验，结果另记。

用户验收待执行：首次显示、底边持续停留、快速移入移出反转、消息自动弹出、动画期间点击/预览、配置背景不透明度、系统减少动画和多 DPI。动画平滑度、实际帧率及首帧表现尚未 Windows 验收。
