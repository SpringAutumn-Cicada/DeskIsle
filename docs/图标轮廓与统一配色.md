# 1.11.24 图标轮廓与统一配色

- test 分支，基于 19c2efa，工作区干净；核对相关图标历史，专用 SDK 已安装。
- 返回机器人与任务栏入口共享图形减少最外层细亮环和重叠端点，改为连续深色外缘、浅蓝主轮廓及单一面罩底，保留造型与表情，减少深色背景上的碎边感。
- 电池外框、数字和充电符号统一绑定 StatusKey 前景色及悬停色，删除绿色底色和电量变色。
- Dock Wi-Fi 弧线由 2 增至 2.5 DIP，弹窗由 2.6 增至 2.9；加大扇形展开角度，初始图标及运行时路径同步。
- 不改操作、无线连接行为、机器人拖动与卡片固定。
- 未运行测试、lint、独立类型检查或 Windows 交互验收，仅执行授权发布与包校验。
- 待用户验收：深浅背景轮廓清晰度、Wi-Fi 视觉重量、电池配色一致性及 DPI 效果。
