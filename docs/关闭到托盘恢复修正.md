# 1.11.6 关闭到托盘后的应用恢复

- 分支 test，基于 7cf43b9，开始时工作区干净；项目专用 Windows SDK 已安装。
- 修正 Explorer 承载的托盘按钮因 PID 不同无法自动匹配的问题：通知区内唯一的产品名/应用名匹配可以自动恢复，保留 PID 优先级及歧义选择。匹配要求完整名称或明确分隔边界，不使用任意子串；微信补充 Weixin / WeChat / 微信别名。
- 首先对核对过的真实托盘图标执行双击；命中图标内部子元素也允许，但不点击覆盖窗口。无点击入口时调用 UIA Invoke；动作后仍未恢复则等待后对同一个目标尝试 Invoke，不切换其他应用或启动新进程。
- 支持托盘箭头 AutomationId，展开后等待图标出现，避免仅等待 200ms 就判定缺失。
- Dock 图标与隐藏预览继续使用同一恢复流程，只有观察到同路径窗口可见、可操作且进程获得前台才算恢复成功；不强行显示隐藏 HWND。
- 本次未运行测试、lint、独立类型检查或 Windows 交互验收。仅执行已授权的发布构建、ZIP 与复制哈希校验。
- 用户验收待进行：微信、钉钉等关闭到托盘后，从 Dock 图标及预览恢复，反复关闭/打开，无新实例；隐藏图标折叠/展开及 Explorer 重启。
- 限制：Windows 仍需提供可访问的托盘控件；同名多实例需用户选择，权限差异或第三方自绘托盘仍可能不支持。无法在本环境确认所有客户端功能通过。
