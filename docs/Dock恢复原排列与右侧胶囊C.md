# Dock 恢复原排列与右侧胶囊 C

版本 1.8.1；分支 test。

按用户最新要求取消 C2 居中时间与双侧应用分区，恢复左侧 HH:mm 时钟、中央单排应用、右侧四键控制胶囊。应用区内固定应用在前，未固定运行应用在后，两者均存在时以细分隔线区分；保持既有顺序、去重、固定排序及窗口切换。

仅采用最初方案 C 的右侧一体控制区：依次显示桌面、原生任务栏、任务管理器、设置，统一冰蓝线条、淡渐变胶囊底与细分隔、悬停轻亮及底灯。取消左右对称预留空白，单应用区按内容占宽，超宽时统一滚动。保留显隐动画、提醒方案 C、微信图标修复、预览和时间更新。采用新的正向修改提交，不回退或覆盖已有历史，不修改用户配置。

开发自验：起始工作区干净，核对近期提交和布局文件，专用 SDK 已安装；完成代码审阅。未运行测试、lint、独立类型检查或 Windows 交互验证，发布和包校验另记。

用户验收待执行：恢复后的排列与留白、右侧胶囊悬停及四键操作、应用固定/取消固定和排序、超宽滚动、预览锚点、显隐动画及高 DPI。实际视觉与交互尚未 Windows 验收。
