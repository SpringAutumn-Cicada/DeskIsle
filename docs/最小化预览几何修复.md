# 2.1.5 最小化预览几何修复

- test 基于609e8cb，工作区干净；已核对提交、相关实现、AGENTS；沿用项目SDK发布。
- 用户日志正常窗口DWM尺寸匹配可见边界；最小化窗口缺少frame，其尺寸比源画面宽22、高11，导致可靠性检查拒绝。另一个最小化窗口差值不同，不能一律固定补偿。
- 外框、可见边界、圆角现在完整采样成功后一起更新，瞬态读取失败保留上一完整快照；每次悬停开始前补采仍可见的窗口。
- 程序启动前已经最小化、没有快照的可调整大小窗口，使用GetDpiForWindow与GetSystemMetricsForDpi的缩放边框及填充边框推导左右和底部可见边界；不写死11px。尺寸仍不匹配则保留小预览，不移动真实窗口。
- 默认关闭的诊断增加host实际外框、client客户区、clientOrigin屏幕原点、sourceDpi/hostDpi，保留现有源裁剪/目标矩形记录。用于继续定位正常窗口内部偏移，没有日志证据前不额外改动内容坐标。
- 未运行测试、lint、独立类型检查或Windows交互验收。自定义边框/初见即最小化贴靠窗口可能仍缺少准确位置，指标推导不匹配时降级；正常窗口内部偏移仍待新日志定位。
