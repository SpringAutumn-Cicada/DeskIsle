# 移除桌面挂载与预览 B 样式

分支 test，版本 1.4.1。

取消“尝试桌面模式”“切换浮动模式”和“查看显示模式”菜单，删除启动自动挂载、宿主重连及 WorkerW/SetParent 实现。卡片统一使用独立浮动窗口，保留原有返回桌面的显示恢复、桌面图标控制和拖动定位；不再把卡片变为 Explorer 子窗口。已有进程需退出后使用新版本启动，才会解除旧版本运行中的挂载状态。

采用用户选定的预览 B：保留公共外面板和内部圆角卡片，卡片底色与原生画面留边统一；悬停仅轻微提亮整体卡片，内层矩形不再单独变亮，内卡描边保持固定深灰蓝。画面边距缩至约 2 DIP，取消按下时画面矩形的明显亮色，保留标题行关闭按钮悬停红色反馈。不改变组合识别、关闭范围和预览显示生命周期。

开发自验：核对 Git 状态、近期提交及相关文件历史，确认项目专用 SDK 已安装，完成代码审阅；未执行测试、lint、独立类型检查或 Windows 交互验证。发布和包校验另记。

用户验收待执行：启动时卡片可见、菜单不含桌面模式、Win+D/退出全屏后的浮动卡片恢复、拖动及弹窗、B 样式的边距和悬停统一、单窗/组合切换和关闭。浮动模式依赖现有桌面恢复逻辑，不保证所有桌面切换场景完全无延迟。
