## 使用方法

完全退出旧DeskIsle，在2.1.9解压目录PowerShell运行。每次对照都使用同一个未移动的正常窗口，并观察文字/分隔线而不只看角落。

显式源基线：
```powershell
$env:DESKISLE_PEEK_DIAGNOSTICS = "1"
$env:DESKISLE_PEEK_SOURCE_MODE = "explicit"
$env:DESKISLE_PEEK_SQUARE = "0"
Start-Process .\DeskIsle.exe
```

退出后，将SOURCE_MODE改为full再启动。宿主与目标区域保持相同，仅省略源区域标志。如果只有显式源右移，下一步针对源裁剪修复；若两者都右移，再保持full且设DESKISLE_PEEK_SQUARE=1单独对照轮廓。

日志：%LOCALAPPDATA%\DeskIsle\peek-geometry.log，增加requestedCorner、corner和cornerResult（设置轮廓的HRESULT）。实际生效仍以Windows显示为准。读取：
```powershell
Get-Content "$env:LOCALAPPDATA\DeskIsle\peek-geometry.log" -Tail 30
```

结束后从当前PowerShell移除这三个环境变量再启动，即恢复默认模式。无需修改系统环境变量。

- 对照开关不会同时叠加两种画面；诊断日志默认关闭，沿用1MiB大小限制，不记录标题/内容。
- 整体移位、透明合成与缓存源原点仍未通过实测排除。最终修复提交依赖用户对照结果，本次只交付可重复对照能力，不预先更换默认逻辑。
