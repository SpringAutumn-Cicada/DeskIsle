# 0.5.4 删除确认弹窗美化

将应用自己的系统MessageBox删除确认替换为深色圆角WPF模态窗口，配色与卡片一致：矢量删除图标、文件名和可选择复制的完整路径、简短回收说明、取消与删除操作。默认焦点与Enter默认行为为取消，Esc/关闭按钮取消，删除需明确点击或键盘聚焦激活；确认期间阻止卡片关闭和程序退出。长路径及小工作区支持内容滚动，操作按钮保持底部可见。

本次仅改变应用确认窗口，Windows Shell后续回收站、权限或错误提示由系统显示，不修改系统窗口样式，不改变删除及不可回收场景的确认逻辑。未对真实文件执行删除。

变更文件：DeleteConfirmation.xaml/.cs、MainWindow.Delete.cs、DeskIsle.csproj、README及本文档。未执行自动化测试、Windows视觉或键盘验收；待用户检查外观、高缩放、长路径、取消/确认和回收操作。

追加用户要求：新建文件夹/TXT/Markdown表单改用独立模态窗口，固定400×360 DIP（极小工作区限制最大尺寸），不跟随卡片尺寸。复用原有名称、路径、创建与取消逻辑，打开后自动聚焦名称；Alt+F4取消，创建期间禁止关闭，位置选择器归属该弹窗。表单内容可滚动、操作按钮固定。未执行Windows交互验收。
