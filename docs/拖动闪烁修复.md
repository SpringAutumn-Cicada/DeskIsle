# 0.4.1 拖动反馈闪烁修复

分支test。用户反馈拖动时鼠标所在文件闪烁。

代码检查发现：Window的PreviewDragLeave会接收到子图标、文字、行容器之间切换产生的离开事件，原逻辑每次直接删除Adorner并停止滚动计时器，下一次DragOver又创建，造成拖动反馈反复拆装。同时系统悬停/焦点背景与自定义目标高亮叠加。

改为仅当指针确实离开文件视口时隐藏预览；同一次拖动复用同一个Adorner，返回时重新显示，落下/取消/关闭才删除。拖动期间停用图标常规悬停和焦点高亮，由拖动覆盖层统一绘制目标。预览位置/目标未变时不重复请求绘制，边缘滚动未产生实际位移时不重复更新。

原文件路径、引用顺序保存机制和外部拖入行为保持不变。未主动运行自动测试或Windows交互验收；仅执行用户已授权的交付构建、打包和完整性校验，结果完成后追加。

待用户验收：慢速跨越图标、名称和间隙，停留不动，跨行和边缘滚动；离开后返回、Esc取消、松手排序；确认目标不闪烁，拖动结束后普通悬停和键盘焦点样式恢复。

边缘滚动的预览更新改为监听ScrollChanged的实际垂直位移，避免ScrollToVerticalOffset尚未完成布局时提前计算目标；隐藏或清理预览后停止更新，清理时解除订阅。修复提交bf4d46a，滚动同步提交cb1ad42。
