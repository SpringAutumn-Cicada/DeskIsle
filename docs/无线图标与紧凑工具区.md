# 1.11.10 无线图标与紧凑工具区

- 分支 test，基于 1ca06c9；开始时工作区干净，项目专用 Windows SDK 已安装。
- Wi-Fi / 蓝牙采用 26 DIP 固定画布、统一圆角线条和浅青配色。Wi-Fi 改为同心弧和圆点，蓝牙保持窄身比例，避免按几何外框拉伸造成两者视觉重量不一致。
- 无线左侧开关、右侧详情、实际连接文字和开关发光点继续保留；无交互功能改动。
- 底部三个工具按钮删除常驻中文，改为统一 19 DIP 图标、32 DIP 高圆角轻底按钮；整栏固定 36 DIP。保留中文悬停提示及无障碍名称，点击仍执行原生任务栏、任务管理器和设置。
- 工具区使用专用样式，不影响静音、详情返回和刷新按钮。机器人及主 Dock 不改动。
- 未运行测试、lint、独立类型检查或 Windows 交互验收；仅执行已授权的发布构建和包校验。
- 用户验收待进行：无线图标清晰度与比例、纯图标按钮提示和操作、工具栏高度及整体协调性。
