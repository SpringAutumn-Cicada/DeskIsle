# 标题卡片与组合预览面板

版本 1.4.0，分支 test。

## 操作与行为

按用户参考图调整预览：统一深色圆角外面板，组合卡片置于首页左侧，同应用单窗口卡片依次排列。卡片标题行 28 DIP，显示 16 DIP 应用图标与 12 DIP 窗口标题；组合显示两个图标和“组 |”前缀，长标题自动省略。标题及时同步，不因标题变化重建原生画面。

右上角关闭按钮在悬停当前卡片时显示，位于标题行内，不覆盖缩略图；组合按钮向两个窗口分别发送 WM_CLOSE，单窗按钮只发送给对应窗口。不强制杀进程，源应用可以提示保存或拒绝关闭。点击组合内容或标题恢复两窗口，单窗内容或标题仅切换对应窗口。

画面内容最高约 160 DIP，保持原始比例；组合内保留左右占比，组合宽度上限 400 DIP，单窗上限 320 DIP。面板过宽时整体缩小画面区域，标题保持可读；超出单窗口数量时保留原有分页。鼠标悬停只轻微提亮当前卡片背景/边框，不反复替换颜色对象，组合两画面同步反馈。

保留 1.3.5 的预先测量、定位、原生缩略图复用和禁用自身过渡。关闭按钮改为 WPF 标题行按钮，创建原生画面时不再创建覆盖式关闭按钮。未修改开始菜单或卡片文件操作。
