# 1.9.4 取消独立后台功能

分支 test，基于 9420571；开始工作区干净，项目 SDK 已安装。

按用户要求删除二级栏后台箭头、独立面板、后台图标缓存与全进程扫描列表。上层仅保留工具区和系统状态区。

删除微信启动激活分支，不再因后台恢复调用微信可执行程序。普通点击已运行后台应用只请求主 Dock 预览，不启动新实例、不自动切换原生任务栏、不强制显示隐藏窗口；未运行时固定应用正常启动，右键“打开新窗口”保留用户主动启动行为。

本次会话中曾正常显示的应用窗口，在隐藏后只要句柄及对应路径进程仍有效且未 cloaked，就继续进入主 Dock 分组及预览，标题增加“后台”标识。窗口销毁后移除。未将任意隐藏帮助窗口枚举为主窗口；程序启动前已隐藏且未观察到的窗口无法凭空预览。隐藏后 DWM 未保留内容时，显示图标占位，不承诺后台画面实时更新；点击隐藏预览不尝试恢复内部窗口。用户要求的“看见后台”与窗口恢复为不同能力，后者本版已取消。

实际验证：人工源码审阅；未运行测试、lint、独立类型检查或 Windows 交互验收。自动发布与桌面复制校验另行记录；用户需验收隐藏窗口的缩略图可用性、退出后移除及正常可见窗口切换。
