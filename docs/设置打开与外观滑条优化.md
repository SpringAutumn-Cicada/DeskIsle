# 2.0.6 设置打开与外观滑条优化

- test 分支，基于 25a30ac；中断前仅只读排查，无遗留改动，专用 SDK 与依赖已安装；已检查 Git 状态、近期提交及相关文件历史。
- Dock 设置显示请求合并并推迟到菜单/弹窗输入处理之后，显示后恢复最小化状态并激活；短暂提升层级后立即取消置顶，不长期占据最前。
- 登录启动状态查询从窗口构造移至 Loaded 后后台执行，查询期间仅禁用自启开关，避免同步 COM 查询阻塞第一次显示；真实首次打开原因与效果仍需 Windows 验收。
- 设置说明文字由 11 DIP 增至 12 DIP，中等字重并提高对比度、允许换行；副标题和快捷键提示同步提亮。
- 卡片外观透明度滑条采用青色进度、暗色余量、圆形滑块，提供悬停/拖动圆环与键盘焦点框，显示实时百分比。范围仍为 30%～100%，沿用既有持久化逻辑。
- “退出全部卡片”改为“退出”，保留既有退出行为。
- 版本 2.0.6。未运行测试、lint、独立类型检查、浏览器或 Windows 交互验收。用户待验收：首次菜单打开设置、查询期间交互、说明换行、滑条拖动/键盘调整与持久化、退出。
