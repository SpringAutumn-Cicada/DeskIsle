# DeskIsle 1.0.3 前台点击与清晰图标

## 最小化修复

上版仅在 WM_MOUSEACTIVATE 返回不激活，但在 Button.Click（鼠标释放）才读取前台目标，仍可能被WPF激活/焦点变化影响。此原因来自代码检视，尚未在用户会话内操作复现。

- 为 Dock 设置不激活的窗口扩展样式，应用图标按钮不获取键盘焦点。
- 记录鼠标按下时的前台窗口，Dock 为前台时可使用此前记录的外部前台。
- 匹配直接窗口及根拥有者，避免模态子窗口导致无法识别应用组。
- 前台图标点击发送系统最小化命令；非前台应用激活，已最小化的单窗口应用恢复，多窗口组保留窗口选择。

## 清晰度

- 优先请求256像素 Shell 原图，极高缩放下最高512，不先将小图人为放大到固定像素。
- 读取32位透明像素生成冻结位图，释放位图/DC/COM资源；旧式无Alpha图标按不透明处理。
- 移除图标1.12倍缩放动画，悬停改用背景反馈，避免动画过程中多次采样。
- 阴影从内容父层分离，图标不再跟随整个容器的阴影离屏效果处理。
- 保留DPI像素对齐及一次高质量缩小；源应用没有高清图标时仍受源素材限制，不承诺凭空增加真实细节。

## 文件范围与边界

修改 `DockNative.cs`、`DockController.cs`、`DockWindow.xaml`/`.xaml.cs`、`DockApps.cs`、版本与说明。原卡片文件操作和用户配置未改，没有启动新版或操作真实用户窗口。

## 待验收

1. 普通非管理员应用前台时点图标最小化，再点恢复；从其他应用点图标先激活。
2. 多窗口、模态弹窗和管理员应用分别检查。Windows消息权限或应用禁用最小化可能限制行为，不能把此类操作假报成功。
3. 100%、150%、200%缩放及悬停时比较图标边缘、透明区域和文字；确认背景透明度设置保持有效。
4. Dock 无重复缩放动画，设置、排序、空桌面常驻和全屏避让不回退。

不运行自动化测试、lint、独立类型检查或 Windows 交互验收；最终构建与包完整性结果另附。
