# 2.0.0 显示桌面按需恢复

- 分支 test，基于 215c3e7；开始前工作区干净，项目专用 SDK 与依赖已安装。
- 桌面前台恢复只在卡片隐藏、最小化或层级异常时修复并重绘，正常卡片不再强制重绘。
- 保留 100/250ms 有界延迟恢复，用于 Explorer 尚未完成转换的情况；延迟检查不再刷新正常窗口。
- 保留其他应用获得前台时的首次画面修复，避免退出全屏后露出的卡片残影；不重新加载卡片内容、不重建窗口。
- 版本升为 2.0.0。未执行测试、lint、独立类型检查或 Windows 交互验收。
- 用户验收待进行：显示桌面、重复显示桌面、全屏退出，以及卡片被最小化后的恢复。Windows 自身合成转换仍可能产生视觉变化，不能保证所有环境完全无闪动。
