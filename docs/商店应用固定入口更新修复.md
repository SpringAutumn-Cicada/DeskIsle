# 2.0.11 商店应用固定入口更新修复

- 分支 test，基于 a38b2e8；起始工作区干净，检查近期提交、图标与固定入口相关文件历史，项目专用 SDK 与依赖已安装。
- 只读现场确认：固定项引用 Terminal 1.24.12741.0、记事本 11.2607.14.0，路径已不存在；当前注册版本为 Terminal 1.25.3131.0、记事本 11.2609.11.0，执行别名 wt.exe / notepad.exe 仍存在。不是单纯开机文件盘加载慢。
- 为这两类明确识别的 WindowsApps 包路径解析当前用户已注册安装位置，读取当前版本图标；无可读路径时尝试稳定 AppsFolder 应用标识，不依赖过期 EXE。
- 启动优先使用用户执行别名；别名不可用时交给 Explorer 打开稳定的包应用标识，不直接启动旧版 WindowsApps 路径。别名通过文件属性检查识别重解析入口，不单靠 File.Exists 判断可启动性。

- 运行窗口按包身份匹配固定项，避免版本更新后出现第二个运行图标。固定顺序和用户原路径配置保持不变。
- 固定项每30秒重新解析；不可用/暂未解析的项目在后续刷新重试，图标缓存随实际资源路径改变而更新。仅修复 Terminal 与记事本已识别包，其他未识别商店应用仍可能需要重新定位。
