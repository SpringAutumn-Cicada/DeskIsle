# 1.11.0 单层 A2 控制中心

分支 test，基于 ddce535。工作开始时 Git 干净，已核对相关布局历史与项目专用 SDK；不修改全局配置。

取消常驻二级 Dock 和支架，将状态入口放回主 Dock 显示桌面按钮右侧。主栏深灰底色、时钟、应用顺序与提示点沿用。电池仅在主栏显示，数字内嵌电池。控制面板不展示电池和后台应用。

A2 紧凑控制卡上排为 Wi-Fi/蓝牙分段按钮：左侧开关无线电，右侧进入列表，不改变开关；状态为读取到的真实 Radio 状态，权限/硬件策略失败明确提示。Wi-Fi 开关不禁用有线网络。详情页有返回、无线开关、刷新、滚动列表及更多系统设置。

Wi-Fi 列表通过 Windows WiFiAdapter 请求访问并扫描，标记已连接网络和信号；点击尝试用系统已有凭据连接，不收集或保存密码。需要密码、认证、位置许可时引导到系统 Wi-Fi 设置。蓝牙列出系统已配对的传统/LE 设备，设备连接和新增配对进入系统蓝牙设置，避免伪造通用设备连接能力。

音量滑条和静音直接控制默认输出端点，并跟随状态刷新。底部三个按钮为原生任务栏、任务管理器、Dock 设置。面板点外关闭；开启期间 Dock 保持显示。异步列表使用页面版本检查，防止返回或关闭后覆写新页面。

接入 Windows Runtime 官方 API，将应用目标平台明确为 net10.0-windows10.0.19041.0；仍面向 Win11 x64 自包含交付。参考：微软 Radio.RequestAccessAsync、WiFiAdapter 和 BluetoothDevice 官方文档。没有改动全局 SDK 配置。

开发验证仅人工审阅，未执行测试、lint、独立类型检查或 Windows/浏览器交互验收。最终按持续授权发布便携包并验证 ZIP 与复制哈希，不能据此记为功能验收通过。
