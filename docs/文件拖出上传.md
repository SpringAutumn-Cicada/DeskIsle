# 0.5.6 文件拖出上传

中断核对：开始时test工作区干净，最新提交6ae4221，无待续的上传改动。此前拖动仅携带私有排序格式，外部上传控件无法识别。现在同时提供标准FileDrop/CF_HDROP真实路径和原有排序数据。拖动允许效果统一为Copy，卡片内用相同效果完成排序；不向外部开放Move效果，不在拖动结束后删除源文件。跨卡片私有排序数据仍拒绝，不改变既有行为。

支持单个现有文件/目录，失效路径提示。网页/客户端需接受文件拖放；文件夹上传由目标决定。程序只交付拖放数据，上传由用户释放鼠标的目标执行。不进行网络上传测试、不读取文件内容、不移动或删除文件。

变更文件：MainWindow.Reorder.cs、DeskIsle.csproj、README及本文档。未运行测试或Windows交互验收；待用户以临时文件检查上传区、Esc取消、内部排序和资源管理器复制。
