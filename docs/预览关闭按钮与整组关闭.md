# 预览关闭按钮与整组关闭

版本：1.3.2；分支：test。

每个窗口缩略图右上角增加 22 DIP 微型关闭按钮，深色圆角底、细线叉号，悬停和按下采用红色反馈。按钮使用独立原生拥有窗口覆盖 DWM 画面，避免被预览遮挡；按下后拖出按钮松开不关闭，按钮不激活源窗口。组合预览的左右窗口各有独立按钮，只向对应窗口发送 WM_CLOSE。关闭后沿用现有存活检查移除缩略图，全部窗口退出后收起预览。

Dock 应用右键取消逐窗口切换、逐窗口关闭条目，改为唯一的“关闭全部窗口”；对当前应用组的窗口去重后异步发送 WM_CLOSE，不强制终止进程，未保存文档仍由应用正常提示。此处的“全部”指 Dock 当前枚举到的应用窗口，不包含隐藏后台进程；应用拒绝或取消关闭时窗口保留。

开发自验：完成代码审阅；不执行自动化测试或 Windows 交互验收。按项目交付授权执行最终发布构建、ZIP CRC 与桌面副本 SHA256 校验，结果追加在下方。

用户验收待执行：单窗口和 Edge 多窗口的按钮命中、组合预览分别关闭、悬停反馈、按钮拖出取消、关闭未保存文档、右键全部关闭、多缩放显示以及预览退出后的资源释放。
