# 2.0.3 后台窗口误提醒修复

- test 分支，基于 75acfaa；开始前工作区干净，核对近期提交与相关历史，专用 SDK 与依赖已安装。
- 现场线索：2.0.2 日志中 msrdc.exe 进程触发 pending，此后未清除；原实现允许任意后台窗口通过进程路径加入提醒，但 Dock 不一定存在可查看的入口。
- 应用枚举和提醒共用有效窗口筛选：有效、可见、非 owned/tool/桌面窗口、有标题、未被虚拟桌面遮蔽。最小化窗口仍可见，保留其提醒。
- 提醒必须匹配 Dock 应用快照中的实际窗口，不再把未知辅助窗口映射为整个应用消息。新窗口早于快照发出信号时，仅对有效窗口暂存一次，刷新列表后再核对；未进入列表的候选丢弃。
- 已有提醒若入口消失、窗口隐藏、关闭或不再满足有效窗口条件，立即清理；每轮应用快照更新后再次核对。
- 不按进程名屏蔽 WSL/msrdc，也不读取真实未读数；有效应用的非聊天窗口闪烁仍可能触发提醒，不能把系统注意信号等同于真实消息。
- 保留有效应用未查看持续显示、实际进入前台清除、多应用独立处理、手动原生模式不强行切换。原有无未最小化应用时 Dock 常驻桌面的规则不变。
- 开发侧仅完成代码审阅，未运行测试、lint、类型检查、浏览器或 Windows 交互验收。待用户验收：后台辅助窗口不挂住、微信有效窗口提醒持续、切回清除、新窗口信号时序与窗口隐藏清理。
