# 1.11.15 Dock 显现闪帧修复

- test 分支，基于 2cea7bc；开始时工作区干净，专用 SDK 已安装，核对显隐代码历史及调用关系。
- 识别风险：撤销透明度动画后才写最终基础值，可能暴露旧透明值；Show/布局更新后立即开启动画，尚无首帧准备；控制器 SetWindowPos 同时带 SHOWWINDOW，绕过显隐统一入口。
- 显现时先保持透明并等待两个 Rendering 回调，再统一启动淡入位移，避免首帧以未准备布局显现。隐藏、再次切换与关闭均清理回调并以版本号防止过期启动。
- 中断及完成动画时先设置基础值，再移除动画时钟，避免归零闪帧；控制器只调整置顶不再发额外显示标记。
- 保留机器人、拖动行为、180ms 显现与 140ms 隐藏及返回显示保护。
- 未运行测试、lint、独立类型检查或 Windows 交互验收，仅执行授权发布与包校验。
