# Dock 居中时间控制舱 C2

版本 1.8.0；分支 test。

采用用户确认的 C2 效果图布局：左侧固定应用；中央一体胶囊控制区按“显示桌面、原生任务栏、HH:mm 时钟、任务管理器、设置”排列；右侧仅显示未固定的运行应用。固定应用在运行时不在右侧重复出现，保留原有固定项顺序、拖拽排序、运行窗口切换、预览和提醒状态。

左右应用区取相同宽度，以较多的一侧应用数量计算并按主屏宽度限制，确保时钟始终位于 Dock 与屏幕中心。左侧应用靠右排列、右侧靠左，应用数不一致时外侧留对称预留空间，不强行放大图标；超出空间时两侧分别水平滚动。所有应用都为空时只显示中央控制区。

中央胶囊采用深蓝渐变底、细冰蓝轮廓与低对比分隔线，四个工具符号统一 23 DIP、1.7 DIP 线宽及相同点击尺寸。悬停为淡蓝洗色与短底灯，按下减弱底色反馈，不使用独立方框或位移动画。保留已确认的时钟配色与仅时间显示，功能行为不变。
