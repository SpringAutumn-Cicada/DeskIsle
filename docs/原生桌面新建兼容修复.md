# 2.0.9 原生桌面新建兼容修复

- test 分支，基于 1443af7；起始工作区干净，已检查近期提交、相关历史和项目约定，专用 SDK 与依赖已安装。
- 用户补充明确发生于 Windows 桌面直接新建：0x80004005、或卡片刷新但没有新文件；截图另有操作已不存在 ZIP 的提示，不能据此认定为同一原因。
- 代码确认旧版以 ShowWindow 隐藏 Explorer SysListView32，Shell 自身视图标志不一定一致。这是可修复的兼容风险，尚未执行现场复现，不能认定所有 0x80004005 都源于此。
- 改用桌面 IShellWindows/SWC_DESKTOP → IServiceProvider/SID_STopLevelBrowser → IShellBrowser/QueryActiveShellView → IFolderView2，读写 FWF_NOICONS。仅改图标显示位，保留 Explorer 控件、文件内容、其他视图标志和普通文件夹。
- COM 接口布局按微软 win32metadata SDK 头核对；对象/接口指针按所有权释放，失败保留恢复记录，不回退到强制隐藏 HWND。状态查询缓存一秒以合并多卡片查询。
- 旧恢复标记兼容：仅迁移旧版 raw ShowWindow 隐藏时显示旧控件，新版本不再直接隐藏控件。退出沿用恢复入口，不主动修改本机现场状态或重启 Explorer。
- 取消普通前台切换触发全卡片 InvalidateVisual/RedrawWindow；只对确实恢复显示/最小化/层级的卡片重绘，继续保留虚拟桌面保护和不抢焦点。全屏退出画面恢复改依赖原生合成，需要用户回归验收。
- 回收站取消/完成后清理本版新增的“正在移入回收站”状态文案。
- 版本 2.0.9；未运行测试、lint、独立类型检查或 Windows 交互验收，也未实际新建/删除文件。用户验收：升级旧隐藏状态、桌面右键新建文档/文件夹与立即命名、default 收纳、图标隐藏/显示及退出恢复、Win+D和全屏退出。
