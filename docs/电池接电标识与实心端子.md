# 1.11.30 电池接电标识与实心端子

- test 分支，基于 a1dc8f6，工作区干净；专用 SDK 已安装，核对状态条件与电池轮廓历史。
- 原闪电只判断 BatteryFlag.Charging，接电但固件未提供该位或电池保护暂停充电时不显示。现在 ACLineStatus 在线或 Charging 标志成立均显示闪电；拔电且未充电隐藏。悬停仍区分正在充电与仅接通电源，不伪报实际正在充电。
- 将未闭合的电池头线框拆成实心圆角端子，颜色跟随电池外框。冰青电量长度、低电量暖黄及无数字显示不变。
- 未运行测试、lint、独立类型检查或 Windows 交互验收，仅执行授权发布与包校验。
- 待用户验收：插拔电源的闪电、保护暂停和满电接电、实心端子以及悬停状态说明。
