# 0.4.2 网格间距与插入线修复

- 网格按真实滚动视口宽度计算列数，完整列宽的行整体居中；末行保留完整列宽，不独立居中导致图标错列。滚动模板左右各预留7 DIP，对称保留滚动条空间，显示或隐藏滚动条不影响两侧留白。
- 插入线按“插入槽位”统一计算，同一行相邻两项之间取左项右边缘和右项左边缘的中点，从左项右半区或右项左半区进入显示同一条线，目标高亮也统一。行首、行尾采用边缘槽位；跨行时统一显示下一行行首。
- 保持图标尺寸、排序持久化和实际文件不变。布局和拖动绘制涉及MainWindow、FileTile行模型及ReorderAdorner。

仅执行交付所需构建发布和包完整性/复制校验，未运行自动测试或Windows图形界面。待用户验收：不同窗口宽度、滚动条显示/隐藏和末行不足时左右对称且列对齐；同一间隙左右两侧来回拖动，绿线不左右跳位；跨行、首尾、边缘滚动及排序保存正常。
