# 0.5.1 文件删除与恢复修正

文件/文件夹右键“删除…”与“移出卡片”分开。确认框显示真实路径，默认选择否；随后使用Windows Shell回收操作及系统确认/错误提示。不支持回收的位置可能由Windows提示永久删除，用户可取消；应用不提供直接永久删除入口，不在回收失败后自行删除。成功后移除当前卡片同路径引用并保存、刷新；取消或失败保留引用。其他卡片引用不自动清理，避免误移除。删除文件夹包含其内容，须确认真实路径。

变更：MainWindow.Delete.cs、文件菜单、关闭保护、版本及README；恢复监控修正见《恢复优化与新建文件.md》。用户反馈0.5.0偶发全屏恢复变慢，移除高优先级密集重试与过早的帧完成判据；并未测量端到端时延，不能宣称零延迟。

本轮不对真实文件做删除试验，不运行自动化测试或Windows交互验收。用户可用临时文件/空文件夹检查删除确认、取消、回收站还原、占用失败、多卡片引用及全屏返回表现。
