# 2.0.2 应用提醒持续显示

- test 分支，基于 52dbd20。核对上次中断后工作区干净、没有已应用的 30 秒冷却修改；专用 SDK 与依赖已安装。
- 按用户最新要求取代 30 秒冷却方案：收到系统窗口提醒后，只要还有未处理应用就保持 Dock 显示，不受五秒期限、鼠标移开或普通全屏隐藏规则影响，不抢焦点。
- 同应用重复信号只合并状态，不重置提醒起始时间或反复触发弹出动画；原有呼吸光环前五秒强、之后弱的视觉效果保留，五秒仅影响光环强度，不控制显示时长。
- 应用实际进入前台才清除提醒；支持对应句柄、同进程窗口、同可执行文件应用组。点击恢复失败不会仅因点击而清除。查看任一窗口表示查看该应用，不能判断聊天已读。
- 多应用独立清除；全部处理后恢复原有自动隐藏规则，下一条系统提醒立即可触发，没有冷却计时。源窗口销毁也清理失效提醒。
- 手动原生任务栏模式不强行切回；返回 Dock 后仍有未处理提醒则继续显示。关闭/退出 Dock 清理提醒状态。
- 状态新增与清除写入现有轮换诊断日志，不逐条记录重复信号、不记录聊天内容。
- 仍依赖系统窗口闪烁信号；仅托盘或通知且未发出信号的消息不能保证捕获，独占全屏也不能保证覆盖。不能保证与原生任务栏的全部通知行为一致。
- 开发侧完成代码审阅，未运行测试、lint、独立类型检查或 Windows/真实微信消息验证。用户验收待进行：持续显示、切回清除、多个应用独立处理、失败点击不清除、原生模式切换与全屏表现。
