# 预览整卡悬停增强

版本 1.4.2；分支 test。

按确认设计，卡片默认底色 #202936、悬停 #303E50；默认外边框 #344252、悬停 #829AB5，标题从 #DDE5EF 提亮到白色。边框固定 1.5 DIP，内边距由 4 调为 3.5 DIP，内外尺寸不因悬停改变。

原生缩略图画面留边同步使用卡片底色，不增加独立矩形高亮，不改变内容透明度。组合卡片整体响应；关闭按钮继续随卡片悬停出现，按钮自身悬停变红。保持现有画面比例、点击行为、显示时序与生命周期，不增加位移、缩放或弹跳动画。

开发自验：开始前工作区干净，检查近期提交及文件历史，专用 SDK 已安装；完成代码审阅。未执行测试、lint、独立类型检查或 Windows 交互验收。项目授权的最终发布及包校验结果另记。

用户验收待执行：单窗和组合卡片悬停色差、画面留边和标题背景一致、关闭按钮反馈、不同 DPI 的边框清晰度及布局稳定性。视觉效果未经 Windows 验收。
