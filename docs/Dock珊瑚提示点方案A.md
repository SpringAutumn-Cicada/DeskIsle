# Dock 珊瑚提示点方案 A

版本 1.5.3，分支 test。

采用用户选择的效果图方案 A：移除琥珀色方框、整块底色及柔光；图标保持原色。右上角为 6 DIP 珊瑚红 #FF7B72 提示点，加 1 DIP 深色分隔边，总占位 8 DIP，覆盖在图标层上方，不参与鼠标命中，不显示未读数字。底部提醒指示灯为同色 8×2 DIP 圆角短线。
