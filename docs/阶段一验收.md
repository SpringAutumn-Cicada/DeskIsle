## 遗留问题

桌面模式使用未公开层级，跨 Windows 版本兼容性未证实。Explorer 重启若导致子窗口被系统销毁，当前恢复逻辑可能不足，需要根据实测修复。当前原型没有托盘或位置恢复；若卡片不可见，可在任务管理器结束 DeskIsle 后重开。

这是阶段一原型，不代表完整首版交付；阶段二、三尚未实现。不得将自动构建通过写成 Windows 交互验收通过。
